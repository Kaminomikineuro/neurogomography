# Проект: аниме «Белая кровь» (студия)

Автор пишет по-русски. Отвечать по-русски, просто и по шагам: автор не программист.
Работает на Windows через GitHub Desktop, ветка `White-blood` и `main`.

## Роли
- **Claude** — шоураннер и хранитель канона: раскадровка, промпты, логика, сверка с книгой, порядок в данных.
- **Кодекс** — художник. Студия вызывает его через `codex exec` (см. `AGENTS.md`).
- **Автор** — решения, правки, утверждения в интерфейсе студии.

## Где данные
- `studio/data/project.json` — стили (`activeStyle`), палитры, персонажи (token, лист, версии), локации, правила канона (`rules`), открытые вопросы (`questions`).
- `studio/data/episodes/s01e01.json` — сцены и кадры: `img` и `vid` промпты, `characters`, `location`, `versions`, `selected`, `status`.
- `studio/inbox.md` — журнал правок и заметок автора. **В начале сессии прочитать новые записи** и разобрать их: канон, логика, промпты.
- `studio/canon/book/` — текст книги по главам (см. там README: что актуально, что старое). Серия 1 = `Т2-01 Это Грань.txt`.
- Исходная раскадровка: `Аниме/1 серия - демка/Серия_1-2_раскадровка_Т2_гл1.md`. Визуальный канон: `Аниме/Карты и виды местности/Эльтарион/АРТ_Эльтарион_визуал_v1.md`.

## Правила
- Раскадровку правим в `.md`, потом запускаем `python studio/tools/import_storyboard.py`. Он сохраняет версии и статусы, а правки промптов из студии побеждают.
- Новые правила канона добавлять в `project.json → rules` (регулярки `when`/`unless`). Ответы автора на вопросы переносить из `questions` в канон.
- Проверка: `node --check studio/server.mjs studio/public/app.js`. Тест без Кодекса: подложить фейковый `codex` в PATH.

## Реплики и липсинк
- У кадров есть поле `lines`: `who`, `text`, `mode` (`lips`, `offscreen` или `vo`), `src` (`book`, `changed`, `absent`, `short` или `edited`) и `book` (вариант из книги).
- `python studio/tools/lines.py` дополняет новые кадры репликами и пишет отчёт `studio/canon/Реплики_Т2-01.md`. Уже размеченные кадры не трогает.
- Сервер (`videoPrompt`) добавляет реплики `lips` в видео-промпт как блок липсинка.
- Том 2 в `studio/canon/book/Т2-*` взят из актуального docx автора, с ним сверены все реплики серий 1–2. Т1 и Т3 пока только из старой печатной версии.
- Хронометраж под липсинк: если реплика длиннее кадра, говорящий остаётся в кадре с губами, а хвост реплики идёт голосом за кадром на вставке (глаза, реакция собеседника). Такие кадры получают id с буквой: `8.8a`. Импорт их понимает.
- Если в раскадровке поменялся «Звук», `lines.py` разбирает реплики заново (поле `linesFrom`), но только если автор не правил их вручную.

## Комикс
- Вкладка «Комикс» (`studio/public/comic.js`) собирает страницы манги или ленту вебтуна из кадров серии. Раскладка лежит в `studio/data/comics/<серия>.json`.
- Подсказки для автосклейки ведёт Claude в `studio/canon/comic/<серия>.json`: `splash` (кадр на всю страницу), `hero` (страница с большой фигурой героя), `eyes`, `spark`, `stickers`, `captions` (короткие цитаты из книги), `sfx`, `kind` (вид пузыря), `sides` (с какой стороны стоит говорящий в сцене).

## Claude в студии
- В студии есть чат «💬 Claude» (`studio/agent.mjs`, `studio/public/chat.js`): студия запускает `claude -p` в папке репозитория (если Claude Code нет — `codex exec`). Разговоры — `studio/data/chat.json`.
- Порядки работы для таких запусков — `studio/canon/howto/`: `new-episode.md` (серия по главе), `comic.md` (комикс), `studio-chat.md` (любые просьбы из студии). Skills: `.claude/skills/new-episode`, `.claude/skills/comic-hints`.
- Инструменты общие для всех глав: `python studio/tools/import_storyboard.py "<md>"` (шапка `<!-- studio ... -->`), `python studio/tools/lines.py <серии>`.
