# Инструкции для Кодекса (художник студии «Белая кровь»)

Это репозиторий аниме-адаптации романа «Хроники рода Эльтар. Белая кровь».
Твоя роль — рисовать картинки. Логику, лор и промпты ведёт Claude. Всё лежит в `studio/`.

## Если тебя запустила студия (`codex exec`)

Ты получишь промпт, референсы (`-i`) и точный путь для сохранения.
- Нарисуй ровно одну картинку встроенным генератором изображений.
- Сохрани PNG строго по указанному пути. Если генератор сохранил её в `~/.codex/generated_images`, скопируй оттуда.
- Не меняй другие файлы и ничего не коммить.

## Если тебя попросили в чате «обработай очередь студии»

В `studio/queue/*.md` лежат задания: путь для сохранения, референсы по порядку и промпт.
Для каждого задания нарисуй картинку с этими референсами и сохрани её по указанному пути. После этого удали файл задания.

## Правила картинок (канон)

- Формат 16:9, один кадр. Без текста, подписей, водяных знаков и комикс-панелей.
- Лист персонажа или фон локации из референсов — главный источник правды. Лицо, волосы, одежду и архитектуру копируй точно.
- В Эльтарионе солнце красное. Кровь драйков, в том числе Лиама, серебристая. Кровь Повелителя в человеческом облике тёмно-бордовая.
- Дракон стоит на четырёх лапах, глаза жёлтые, пламя чёрное.
- Тела мёртвых даём дальним планом, в тени или силуэтом. Без натурализма.
