# Каталог стилей motion design

Стили 1–15 — переведённые и сжатые «сигнатурные черты» из mg-styles-15: по каждому снят 10-секундный фильм кодом,
прошедший два круга ревью (оценка жюри указана). Стили 16–22 добавлены по той же схеме (жанры из таблицы
рецептов mgaudio и общей практики), без эталонного фильма — для них особенно важен круг ревью.

**Как пользоваться.** Выбери стиль → возьми «Технический маршрут» → «Творческое зерно» замени своей историей,
брендом, текстом и цветами (структура битов остаётся) → **«Сигнатурные черты» не трогай**: по ним стиль узнают
за секунду и по ним же оценивает рубрика. Формат по умолчанию: 1920×1080, 30 fps (24 fps для 3D и cel), ровно
10.000 с, H.264 + AAC 48 кГц, −14 LUFS, true peak ≤ −1 dBTP.

## 1. Покадровая анимация / Line Boil — Frame-by-Frame & Line Boil (`05-cel-boil`) · жюри 8.07
**Суть.** Рисованная покадровая анимация или покадровая фактура поверх вектора. Главный признак — line boil:
линии каждые 2–3 кадра слегка «кипят», картинка дышит. Buck и Giant Ant добавляют cel-эффекты (дым, брызги,
линии скорости) поверх основной анимации — это главный приём против «цифровой стерильности».
**Признаки:** постоянный микроджиттер линий; ритм «на двойках/тройках»; smear-кадры; рисованные дым/искры/брызги; фактура бумаги.
**Маршрут:** Canvas2D, свой кистевой рендер переменной ширины (центральная линия + давление → полигон контура);
boil = 3–4 варианта джиттера, циклически каждые 2 кадра; бумага в режиме multiply. 24 fps.
**Техники:**
- Ритм: при 24 fps основное «на двойках» (фактически 12 fps), быстрые действия — «на единицах», статика — «на тройках».
- Boil-эмуляция: смещение (amount 2–5 px, size ~50) с новой случайной фазой каждые 2 кадра + posterize time 12 fps; честный boil — 3–4 чуть разных прорисовки по кругу (`boil()` в `mg.js`).
- Smear-кадр: в середине быстрого перемещения объект вытягивается на 150–300 % ровно на 1 кадр.
- Cel-FX слой (дым/вода/молния) — покадрово поверх векторной основы (гибрид Buck).
- Бумага поверх всего: multiply 10–15 %.
**Палитра:** чернила #1B1B1B, томатный #E8442E, солнечный #F7C331, кремовая бумага #F6EEDC.
**Зерно:** спичка чиркает (smear на единицах) → выскакивает дух-огонёк (anticipation + squash), танцует на
двойках → взрывается cel-эффектами (клубы дыма, искры, звёзды, линии скорости) → эффекты собираются в
рукописный заголовок, который продолжает «кипеть» на финальном удержании (на тройках).
**Звук:** игривое джазовое пиццикато/ксилофон + мультяшные SFX: чирк, фуух, поп, пуф, блёстки — в кадр.

## 2. Изометрия 2.5D — Isometric (`03-isometric`) · жюри 8.00
**Суть.** Миниатюрный мир в изометрии: город, офис в разрезе, дата-центр. Нет точки схода, всё в масштабе.
Стандарт для архитектурных схем техкомпаний и демо функций приложений.
**Признаки:** изометрическая проекция (30°), никакой перспективы, микросцены, «вырастающие» здания, камера скользит параллельно.
**Маршрут:** Three.js `OrthographicCamera` под истинным изометрическим углом (возвышение 35.264°, азимут 45°) +
мягкие тени + AO; либо SVG c гранями через SSR-матрицу.
**Техники:**
- SSR для граней: Scale по вертикали 86.6 % → Shear ±30° → Rotate ∓30°; три грани собираются из трёх операций.
- Псевдо-3D порядком слоёв: Z-порядок = экранный y; движение по сетке — с наклоном 2:1 в пикселях.
- «Рост» здания: сначала падает основание, стены scaleY 0→1 с overshoot, крыша накрывает через 2–3 кадра.
- Камера только панорамирует (без вращения), параллакс переднего/среднего/заднего плана 1 : 0.8 : 0.6.
**Палитра:** пастель — лаванда (земля), мята, персик, небесно-голубой, белый; мягкие тени.
**Зерно (10 с):** 0–2 с плитки падают волной от центра с подскоком → 2–5 с растут здания, деревья, окна
загораются по очереди → 5–8 с жизнь: машины, поезд, дроны с пакетами, светящиеся потоки данных, ветряк;
параллакс облаков → 8–10 с отъезд: остров парит в пастельной пустоте, заголовок лежит НА изометрической плоскости.
**Звук:** светлая «плаковая» тех-мелодия (FM-маримба), мягкие клики/попы на каждой плитке, воздушный whoosh на отъезде.

## 3. Плоский вектор — Flat / Vector 2D (`01-flat-vector`) · жюри 7.64
**Суть.** База MG: традиция Google Material и explainer-роликов. Геометричные персонажи и сцены из плоских
цветовых плашек, без обводок или с минимальной. SaaS, научпоп, годовые отчёты.
**Признаки:** большие плоские плашки, геометричные персонажи, без градиентов, чистый воздух, насыщенная бренд-палитра, упругие появления.
**Маршрут:** SVG + GSAP (CustomEase / CustomBounce / MorphSVG); motion blur mb=4 на быстрых движениях.
**Техники:**
- Иерархия через родительские null-контроллеры; конечности персонажа — вращение вокруг anchor point (риг).
- **Упругость — душа стиля:** overshoot `cubic-bezier(0.34,1.56,0.64,1)` (в AE — 70–85 % influence); вход в три фазы: подготовка → выброс → возврат.
- Stagger 2–4 кадра; **в каждый момент движется один герой**.
- 30 fps; squash & stretch ~10 % при перемещении.
- Переходы: shape wipe (цветовая плашка заливает кадр) или вылетающий элемент «тащит» склейку.
**Палитра:** ультрамарин #2B2BFF, коралл #FF5A4E, подсолнух #FFC62B, мята #2EE6A8, крем #FFF6E9, чернила #151433.
**Зерно:** один непрерывный кадр. 0–1.2 с в пустое цветовое поле падает насыщенный круг (подготовка → растяжение
→ сплющивание → перелёт → покой) → круг становится солнцем, город выскакивает дом за домом (stagger 2–4 кадра,
у каждого мини-overshoot), облака, птицы → наезд в окно: геометричный персонаж за столом (моргает, кивает),
пиликает телефон → пузырь уведомления разрастается в shape wipe, внутри ритмично взрываются иконки (график
растёт, галочка рисуется, сердце, монета) → всё схлопывается в логотип вымышленного бренда + теглайн,
упругая посадка, 1 с удержания с микродвижением.
**Звук:** future bass/поп ~120 BPM; pop/boing/whoosh на каждое появление, точно в кадр.

## 4. Линейная анимация — Line Art (`02-line-art`) · жюри 7.64
**Суть.** Единственный язык — тонкая однотонная линия, которая сама себя рисует, тянется, поворачивает и
превращается в следующую фигуру: весь фильм одной линией. Люкс, финансы, архитектура, логотипы.
**Признаки:** моноширинная тонкая линия, 1–2 цвета, много негативного пространства, непрерывный рост линии, момент «линия → заливка».
**Маршрут:** SVG paths + `stroke-dashoffset` (`getTotalLength`) + GSAP либо Canvas (`polyline().draw` в `mg.js`);
виртуальная камера следует за пером.
**Техники:**
- Draw-on: Trim Paths 0→100 % / `stroke-dasharray` + `dashoffset`.
- Толщина постоянна весь фильм (2–4 px); на поворотах перо замедляется — `cubic-bezier(0.65,0,0.35,1)`.
- «Одним росчерком»: хвост одной фигуры — начало следующей; путь продуман заранее.
- Линия → заливка: после контура та же форма заливается от якорной точки.
- Круглые концы (round cap) и лёгкий джиттер пути — ощущение руки.
**Палитра:** полночь #0B1320, шампань-золото #E9D7A5 (линия ~3 px), светящийся кончик пера.
**Зерно:** семя → росток → ветви становятся конструкцией здания → контур уходит в линию горизонта → горизонт
поднимается и закручивается в монограмму → заливка золотом от якоря → тонкий разреженный антиквенный
вордмарк. Камера ведёт перо, в конце отъезжает и открывает весь рисунок как постер; старые сегменты тускнеют до ~35 %.
**Звук:** минималистичное фетровое фортепиано + мягкий струнный swell; шорох пера, громкость которого следует
скорости пера; тонкий колокольчик на заливке. *(Демо этого стиля — `templates/film/`.)*

## 5. 3D-рендер — C4D/Blender CGI (`04-3d-render`) · жюри 7.71
**Суть.** Материальная 3D-анимация: мягкий пластик, стекло, металл, ткань + клонеры и физика. Основа премиальных
продуктовых роликов и brand ident (ориентир — ежегодный Maxon Demo Reel).
**Признаки:** PBR-материалы, малая ГРИП, мягкий студийный свет, массивы клонов, мягкие столкновения, «конфетный» мягкий пластик.
**Маршрут:** Blender CLI (`bpy`-скрипт → Cycles с OIDN-денойзом или EEVEE) → PNG-секвенция → ffmpeg; типографика —
отдельным HTML-проходом поверх. Без Blender — Three.js + `MeshPhysicalMaterial` + HDRI + `EffectComposer` (DoF, AO).
**Техники:**
- MoGraph: Cloner + Random/Plain Effector → волна по массиву объектов (в Blender — Geometry Nodes).
- Тройка качества: SSS (подповерхностное рассеивание, «мармелад») + AO + HDRI/трёхточечный свет.
- «Длинный хвост»: 80 % пути за первые 20 % времени, очень медленный финиш, motion blur.
- 24/25 fps + малая ГРИП (ощущение f/1.8) — отличает от «бодрого» 2D на 30 fps.
- Продукт — ось композиции; частицы/жидкость/ткань хореографируются вокруг.
**Палитра:** пастельная студия: розовый мармелад, персик, крем, сирень, акцент хром/матовое стекло.
**Зерно:** поле глянцевых капсул (клонер) колышется волной эффектора → падает надутый 3D-вордмарк с
затухающим пружинным «желе», врезается в поле и раздвигает его → камера с длинным хвостом, финальная композиция ~1 с.
**Звук:** ASMR — мягкие удары, хлюпы, пузырьковые попы, воздушный пэд; удары в кадр столкновений.

## 6. Морфинг формы — Shape Morph (`08-morph`) · жюри 7.64
**Суть.** Одна фигура плавно и непрерывно становится другой: телефон → метка карты, чашка → закат. Ядро
визуального сторителлинга; самое «мастерское» место keynote-анимаций.
**Признаки:** непрерывный контур без скачков, промежуточные фигуры-мосты, морф совмещён со сдвигом/поворотом, сжатие-растяжение в момент перехода.
**Маршрут:** SVG + flubber / GSAP MorphSVGPlugin (настраивай `shapeIndex`); смена фонов цветовыми вайпами.
**Техники:**
- Выравнивание путей обязательно: одинаковое число вершин и соответствующая первая вершина — иначе «узлы».
- Сложное A→B не морфь напрямую: A → простая форма (круг/капсула) → B, каждая половина 8–12 кадров.
- Весь морф с 10–15 % squash & stretch и лёгким вращением — прячет механику интерполяции.
- Скорость максимальна в середине: `cubic-bezier(0.7,0,0.3,1)`, по 3 кадра «подушки» в начале и конце.
- flubber/polymorph подбирают вершины оптимально — намного лучше наивного SMIL.
- Проверяй стоп-кадр середины каждого морфа: ни одного перехлёста.
**Зерно:** чашка кофе → (круг) → солнце → закат над морем → чайка → бумажный самолётик → метка → сердце →
логотип вымышленного бренда. Подэлементы морфятся синхронно (пар → лучи → волны); фон меняется с каждым морфом.
**Звук:** ритмичное «плаковое» арпеджио; тональный whoosh на каждом приземлении морфа — в долю.

## 7. Стикерный explainer — Bold-outline Sticker Explainer (`19-paperclip`) · жюри 7.71
**Суть.** Формат научпоп-каналов (PaperClip): фото вырезаны и обведены толстой белой рамкой → «стикеры»,
вместе с плоскими иконками и точными графиками лежат на огромном холсте; камера панорамирует и зумит,
связывая точки. Стандарт научпопа, финансов, корпоративных роликов.
**Признаки:** фото-стикеры (белая обводка 8–12 px), спокойный сине-серый/молочный фон, плоские иконки + точные графики, гигантский холст, плотный ритм.
**Маршрут:** один огромный холст (например 6000×3000) с трансформацией камеры (длинные ease), SVG-графики, стикеры с белой обводкой 10 px.
**Техники:** вырезка фото + 8–12 px белой обводки (снимает разнобой источников); камера — одним проездом через
все точки; графики растут, цифры считаются (count-up), линии рисуются; каждая фраза диктора = новый визуальный
элемент; 2–3 цвета + моноширинная/гротеск без контраста толщин — «серьёзность».
**Палитра:** #E9EEF2 + сланцевый, акцент #FF5A36.
**Зерно:** «Сколько элементов прячется в телефоне?» Фото телефона-стикер → разнесённые детали с выносками →
таблица Менделеева, клетки загораются → столбчатый график растёт с count-up «70+» → карта мира с маршрутами
поставок → отъезд к типографскому финалу (жирный гротеск, огромная цифра, мелкая подпись). Цифры точные и согласованные.
**Звук:** чистый тех-explainer бед, UI-клики, тиканье во время count-up, мягкий whoosh на движениях камеры.

## 8. Киберпанк HUD / FUI (`22-hud`) · жюри 7.93
**Суть.** Интерфейс из sci-fi кино/игр: неоновые циан/оранжевые каркасы, рамки захвата цели, радары, потоки
мелких данных. «Техно-скин» по умолчанию для обзоров, игровых нарезок, аэрокосмоса, демо AI.
**Признаки:** циан/оранжевые линии, рамки захвата и прицел, вращающиеся радарные кольца, моноширинные столбцы данных и печатающийся текст, гексагональная сетка, свечение.
**Маршрут:** SVG/Canvas слои FUI + Three.js каркасная голограмма (глобус/дрон); seeded-данные; пост-проход glow + scanlines.
**Техники:**
- Каркас прорастает через `stroke-dasharray/dashoffset`, элементы раскрываются по иерархии со сдвигом кадров.
- Радар: вращающийся сектор `conic-gradient` + мигающие цели.
- Цифры: случайные значения 3–5 кадров, затем фиксируются на реальном; печатная машинка + мигающий курсор.
- Захват цели: четыре угловые скобки сжимаются 1.4 → 1.0 (fast-out slow-in).
- Глобально: свечение + лёгкая хроматическая аберрация + сканлайны.
**Палитра:** глубокий тил-чёрный, циан #00E5FF, тревога #FF6A00.
**Зерно:** линии прорисовываются иерархически → данные оживают → цель найдена → скобки защёлкиваются → всё
переключается в оранжевую тревогу «TARGET LOCKED / ЦЕЛЬ ЗАХВАЧЕНА», координаты.
**Звук:** darksynth-пульс + HUD-бипы, сканирующие свипы, восходящий тон захвата, сирена на захвате.

## 9. Коллаж / перекладка — Collage / Cut-out (`06-collage`) · жюри 8.14
**Суть.** Ретро-сюрреализм из вырезанных старых фото, газет и рваной бумаги; корни — Monty Python (Терри
Гиллиам) и плакаты советского конструктивизма. Сейчас сливается с «журнальным» стилем; музыка и стритвир.
**Признаки:** вырезки с белым «ножничным» краем, полутоновый растр, газетная фактура, сюрреалистичные пропорции, рваное стоп-моушен движение.
**Маршрут:** DOM/Canvas с PNG-вырезками (фон удалить, напр. rembg), SVG/CSS белая кромка + halftone; рендер 30 fps, но движение квантуется на сетку 12 fps.
**Техники:** вырезка + 2–4 px белой кромки + halftone; суставы — pivot в плече/локте/челюсти, «марионеточные»
повороты; рот — 2–3 сменных кадра; движение 12 fps или даже 6 fps + ±2 px случайного дрожания («рука
переставляет»); слои: бумага → цветовые плашки → фото → каракули/скотч/наклейки → зерно; переходы — рука
«шлёпает» элемент или переворот страницы.
**Палитра:** крафт/газетная бумага, конструктивистский красный + чёрный, диагональная типографика.
**Зерно:** викторианский портрет (public domain); макушка откидывается как крышка (оммаж Гиллиаму) → внутри
космос, оттуда высыпаются цветы, птицы, планеты, указующие руки, ракета; челюсть на отдельном вырезе хлопает
в такт; руки прихлопывают элементы; рваные полосы; диагональный заголовок; переворот страницы к финалу.

## 10. Аврора и стеклянный морфизм — Aurora & Glassmorphism (`12-aurora-glass`) · жюри 8.07
**Суть.** Огромные размытые цветовые пятна (aurora / mesh gradient) медленно дрейфуют, сверху парят матовые
стеклянные карточки. Liquid Glass (iOS 26) и запуски AI-продуктов сделали это визуальным дефолтом
техбрендов 2024–2026: «медленно, прозрачно, дорого».
**Признаки:** дрейф больших размытых пятен, матовое стекло, 1 px светлая кромка, близкие оттенки с низким контрастом, медленное «дыхание».
**Маршрут:** WebGL: шейдер mesh-градиента + стеклянная линза с преломлением (SDF, хроматическая дисперсия) + DOM/CSS `backdrop-filter` карточки.
**Техники:**
- Аврора: 3–5 больших кругов, blur 80–150 px, каждый дрейфует по безье-пути с циклом 20–40 с.
- Стекло: `backdrop-filter: blur(20–40px)` + 5–10 % белой заливки + 1 px внутренняя кромка 30 % белого + большой радиус.
- Только соседние оттенки (фиолет-синий-циан или оранж-розовый-красный) — контрастные «грязнят»; тёмный фон лучше светлого.
- 3–5 % шума поверх всего против бандинга.
- Ease — почти linear или синус-дыхание; **всё медленно**; текст появляется только opacity + 8 px подъёма.
**Палитра:** индиго-чёрный фон; фиолет/синий/циан/маджента пятна.
**Зерно:** карточки вплывают с параллаксом и лёгким 3D-наклоном, внутри микро-UI (чат, волна голоса,
тумблеры) → WOW: линза Liquid Glass скользит по кадру, увеличивая аврору и карточки → тонкий заголовок.
**Звук:** эмбиент-пэд, мягкий шиммер, очень тихие UI-тики.

## 11. Геометрия / Баухаус — Geometric Bauhaus (`09-bauhaus`) · жюри 7.71
**Суть.** Круги, треугольники, прямоугольники точно двигаются по строгой сетке; основные цвета + чёрный и
белый, механическая рациональность. Баухаус + швейцарский стиль; главный язык кинетических постеров; идеально

**Признаки:** базовые фигуры, красный/жёлтый/синий/чёрный, строгая сетка, вращение вокруг геометрических центров, модульное движение по битам.
**Маршрут:** SVG/Canvas + GSAP на модульной сетке (напр. модуль 240 px), бит-сетка 120 BPM.

6–8 с каскадная волна по сетке на дропе → 8–10 с застывает идеальный постер с швейцарской типографикой
(вертикальный жирный геометрический гротеск + капитель «ФОРМА · ЦВЕТ · ФУНКЦИЯ»). Допустимы бумажный зуб и лёгкое несовмещение печати.

## 12. Ретро 80-х Synthwave / VHS / Y2K (`10-synthwave`) · жюри 8.21 (лучший)
**Суть.** Цитата медиаэстетики эпохи: synthwave — неоновая сетка, закатный градиент, хромированный шрифт; VHS —
сканлайны, цветовой сдвиг, шум плёнки; Y2K — жидкий хром, кислотный зелёный/фиолетовый, скевоморфные окна.
**Признаки:** неоновое свечение, перспективная сетка до горизонта, сканлайны и RGB-сдвиг, хромированные буквы, кислотные цвета, ретро-окна UI.
**Маршрут:** WebGL (перспективная сетка, солнце, шейдер гор) + Canvas хром-текст + CSS/SVG glow; VHS-проход.
**Техники:**
- Тройка synthwave: бегущая одноточечная сетка (цикл по вертикали), многослойный градиентный «полосатый» шар-солнце, двойное свечение (тугое 4 px + широкое 30 px с низкой непрозрачностью).
- VHS-цепочка: RGB split (R и B ±1–2 px) → сканлайны (каждые 2 px 10 % чёрного) → волновое искажение (1–2 глитча в секунду) → маска 4:3 со скруглением.
- Хром: многоступенчатый металлический градиент высокого контраста + bevel-блик + звёздный блик-проход + lens flare.
- Y2K-движение: всплывающие окна, клики курсора, перетаскивание окон.
- Нестабильный fps: ключевые места на 15 fps или 2 кадра назад — «зажёванная плёнка».
**Зерно:** VHS-шум + «PLAY ▶» → полёт над сеткой, восход солнца → хром-заголовок ВРЕЗАЕТСЯ с флэром → неоновое
рукописное слово зажигается как газовая трубка с мерцанием → поездка, chroma bleed, финальный кадр.
**Звук:** synthwave: gated-reverb снейр, арпеджированный saw-бас, пышные пэды, большой аккорд + крэш на ударе титра.

## 13. Пиксель-арт — Pixel Art / 8-bit (`20-pixel`) · жюри 8.07
**Суть.** Крупный пиксель + ограниченная палитра + низкий fps спрайтов: эстетика ретро-игр.
**Признаки:** крупные пиксели и жёсткие края, 8–32 цвета, спрайты 8–12 fps, дизеринг градиентов, CRT-сканлайны.
**Маршрут:** Canvas во внутреннем разрешении 320×180, целочисленное ×6 nearest-neighbour; спрайты как массивы пикселей в коде.
**Техники:** спрайт-лист (бег 6–8 кадров, дыхание 2–4); масштаб только nearest-neighbour
(`image-rendering: pixelated`), никакого сглаживания; тайминг `steps()`, а не плавные кривые; параллакс 3–4 слоёв

**Палитра:** PICO-8-подобная, 16–32 цвета, дизеринг неба.
**Зерно:** герой бежит, прыгает, собирает монеты, отбивает слизня; палитра день → закат; сундук открывается со

## 14. Жидкое движение — Liquid Motion (`07-liquid`) · жюри 7.57
**Суть.** Формы текут, тянутся нитями, капают и сливаются: переход — краска заливает экран, логотип собирается из
капли. Органика, «залипательность», энергия. Музыкальные клипы, еда и напитки, пакеты переходов.
**Признаки:** волнистые края переходов, нити и капли, слияние metaball, вторичные капли догоняют, никаких прямых линий.
**Маршрут:** WebGL2 фрагментный шейдер: 2D SDF metaballs (smooth-min) + псевдо-3D свет по нормалям поля; SDF-текст для логотипа.
**Техники:**
- Жидкий переход: маска с волнистым фронтом, на фронте 3–5 выпуклостей со сдвигом фаз.
- Metaball без шейдера: гауссово размытие (≥20 px) → порог альфы (`feColorMatrix` в SVG / Levels в AE) — шары слипаются сами.
- Нить-разрыв-отскок: уходящая форма тянет тонкую шейку; при разрыве оба конца отскакивают 2–3 кадра.
- Ease быстрый старт — медленный конец `cubic-bezier(0.22,1,0.36,1)`: жидкость «швыряют», она не едет равномерно.
- Вторичные капли отстают на 2–3 кадра (follow-through), при падении сплющиваются.
**Палитра:** тёмная слива фон; глянцевая «конфетная» жидкость горячий оранжевый → розовый → фиолетовый, спекуляр и френель-кромка.
**Зерно:** капли падают со сплющиванием → сливаются metaball-ами (шейки, разрыв, отскок) → большая волна заливает
кадр как переход → жидкость собирается в вордмарк → последняя капля падает с логотипа, круги, удержание.
**Звук:** бульканье, налив, всплеск, капли, глубокий басовый swell под глянцевым синтом.

## 15. Варьете-титры — Variety Show Kinetic Captions (`18-hanazi`, 9:16) · жюри 7.64
**Суть.** Эмоциональные декоративные субтитры из постпродакшна азиатских ТВ-шоу: пухлые скруглённые буквы с
многослойной обводкой, упругое появление, цвет/форма меняются под эмоцию, каждое — со звуковым ударом. Сейчас —

появление на 2–3 кадра позже реплики/звука (естественнее); длительно висящий титр — лёгкий wiggle.
**Палитра:** насыщенные розовый/жёлтый/циан + белые обводки.
**Зерно:** котик-влог: заголовок «Моя доза счастья» → прыгающие «???» → «ШОК!!» во взрыв-рамке с лучами →
«(шёпотом)» мелко → «топчик» с блёстками → капли пота → печать «Одобрено котом».
**Звук:** прыгучий варьете-бед (пиццикато/бас/хлопки) + boing, pop, ding, slide whistle, скретч на «???».

## 16. Кинетическая типографика / Text Flash
**Суть.** Текст — единственный герой: слова врезаются на каждую долю, меняют размер, вес, направление; «快闪»
(быстрый флэш) — до 2–4 слов в секунду. Промо, анонсы, лирик-видео, Reels.
**Признаки:** одна мысль = один кадр; контраст размеров 1:6+; резкие «slam»-удары на биты; инверсия цвета фона на сильных долях; масштабные пролёты камеры сквозь буквы.
**Маршрут:** DOM/Canvas, `opentype.js` для контуров букв (разрыв/морф глифов); бит-сетка из cues.
**Техники:** хит на долю: scale 1.4 → 1.0 за 4–6 кадров + motion blur; между ударами — 1–2 кадра «вдоха»; смена
фона инверсией строго на сильной доле; варьируй ось (горизонталь/вертикаль/глубина) каждые 2–3 слова;
переменные шрифты — анимация `wght`/`wdth`; маска-реверс (текст вырезает фото/видео).
**Палитра:** 2 цвета + 1 акцент (чёрный/белый/кислотный).
**Звук:** trap/EDM 130–150 BPM; `text_hit` (slam/flash/pop) на каждое слово, 808 на ключевых.

## 22. Аниме-опенинг / Манга-панели — Anime OP & Manga Panels
**Суть.** Язык опенингов аниме: быстрые нарезки персонажей, speed lines, импакт-кадры, панели манги,
вспышки, крупные титры с японским/русским текстом. Идеален для книг-фэнтези и персонажных карточек.
**Признаки:** диагональные композиции, speed lines и радиальные «фокус-линии», импакт-кадр (инверсия/монохром на 2–3 кадра), разбиение кадра на манга-панели, параллакс слоёв арта (2.5D), блики-«звёзды», титр с обводкой.
**Маршрут:** HTML/Canvas: арты персонажей как слои (вырезки PNG) с 2.5D-параллаксом (камера двигает слои
1 : 0.7 : 0.4), SVG-панели и speed lines; для «оживления» самих артов — image-to-video нейросеть
(`references/ai-video-generation.md`), затем монтаж и титры кодом.
**Техники:**
- Каждый персонаж — «пресс-кадр» 0.6–1.2 с: быстрый вход (камера-рывок 4–6 кадров `E.out`), медленный дрейф, резкий кат.

- Speed lines: seeded-полосы, обновление каждые 2 кадра (on twos — ощущение рисованности).

**Палитра:** от артов; связующие — глубокий тёмный + 1–2 акцента (например, золото + белый для «Белой крови»).
**Звук:** J-rock/эпик 150–170 BPM или оркестровый гибрид; whoosh на каждый кат, impact на импакт-кадрах, riser к названию.
**Ассеты в этом репозитории:** `Аниме/Карты персонажей книга/*.png` — персонажи, локации, символы родов.

## 23. Vox-коллаж / объяснялка «на виду» — Plain-sight Collage Explainer
**Источник:** HyperFrames `vox-explainer` (Apache-2.0). 60–90 с, голос за кадром, полный метод — `explainer.md`.
**Суть.** Объяснение вещи, которая «прячется у всех на виду»: фото-карточки, газетные слои, жёлтый круг-носитель,
стрелки, маркер-подсветки. Картинка **показывает механизм**, а не иллюстрирует фразу.
**Признаки:** стопки фото-карточек одного формата с джиттером поворота ±1,5–3°, радиус ~18 px и мягкая тень;
жёлтый круг/подсветка; zoom-isolation (наезд в фото 4,5–7× → склейка в вырезанный объект); газетный слой;
нижняя «плашка» с ролью; спокойная полоса субтитров.
**Палитра:** чернила #1A1A1A, жёлтый #FFE619, process blue #66CFFF (заливки; мелкий текст ≥ #3E87A8), specimen blue
#58BCEC, серые #F2F2F2 / #E9E9EB / #8D9399, фон #FBFAF8. Заголовки — тяжёлый гротеск с кириллицей (Archivo Black её не
имеет → Oswald 700, Russo One, Unbounded 900).
**Техники:** **элементы — микро-удержания 12 fps поверх плавных кривых, камера — плавно** (`stepEase` в `mg.js`);
поп карточки scale 1,10 → 1,0 за 0,3 с ступенчато; **подсветки всегда «наезжают»**: `background-size 0→100%` ~0,4 с,
круги — dashoffset ~0,4 с; наезд-изоляция `power4.in` ~1,2 с до 4,5–7×, обратный приход `expo.out` ~1,1 с с 3,2×;
«ползучесть» фона linear 3–4 %/бит; «проезды мимо» с blur ∝ скорости, объект исчезает в кадре, где заполнил экран.
Пол техник на фильм: ≥ 1 zoom-isolation, ≥ 1 обратный zoom-through на развязке, ≥ 2 проезда через заполнение кадра,
≥ 1 вырезка без фона, ≥ 1 газетный слой, круг-раскрытие (0,30 → 0,72 → 0,943 → 1,0 за ~0,45 с); статичные раскладки ≤ ⅓ битов;
два соседних бита не повторяют рецепт. **Наезд в фото должен окупиться внутри него.**
**Звук:** голос — это часы (тайминги слов из транскрипта); тихая подложка, бумажные/щелчковые SFX.

## 24. Двухтонная тушь с кипением — Two-tone Ink Boil
**Источник:** HyperFrames `day-in-my-life` (Apache-2.0). Расширение стиля 1.
**Признаки:** **ровно два тона** — тушь #121110 и бумага #EEE9E0 («пол туши» клампит каждый пиксель); **весь кадр
перерисовывается 8 раз в секунду** (новая «прорисовка» каждые 1/8 с, движение тоже ступенями); двойные контуры
рядом; прямоугольники — 4 штриха с перелётом; сплошная заливка только на важных лицах, остальное — штриховка;
подпись — одна строчная метка в бумажной карточке слева вверху, печатается 20 символов/с рукописным шрифтом.
**Техники:** регулятор `SKETCH` (≈1,8) масштабирует дрожь, отрывы пера, перелёты, рваные края, несовмещение;
**ключевая случайность** `keyRng(key, boilIndex)` в `mg.js` — неподвижные вещи одинаковы внутри одной прорисовки
независимо от того, сколько случайностей потрачено выше; светлые штрихи рисуются после туши (иначе серость).
Стыки: полоса туши уходит **влево** (0,75 с, панорама 90 px с обеих сторон), клякса-«глоток» → рваная диафрагма
(2 на фильм), мотивированное затемнение (лампа гаснет — звук тоже).
**QC:** 7,5–8,5 новых прорисовок/с, > 98 % изменений на 3-кадровой сетке (24 fps), самое длинное удержание ≤ 3 кадров;
полностью залитый тушью кадр (> 97 % пикселей темнее 60) в пределах ±4 кадров от каждого стыка-вайпа.
**Звук:** струнные (смычковые аддитивно, пиццикато Karplus-Strong), без ударных и стоковых стингеров; удары — на
прорисовке, которая показывает событие. Мастер −17 LUFS.

## 25. Печатный генеративный фильм — Print-proof Generative Film
**Источник:** buildfast `generative-film` (MIT): эталон «SŪTRA», 87 с, 96 BPM × 136 долей, каждый кадр нарисован
кодом, каждая нота синтезирована. **Не ИИ-видео.**
**Суть.** Эссе-фильм о культуре/компании/науке в виде печатного оттиска (ризограф). **Идея на главу, а не картинка
на главу:** каждая сцена показывает механизм (сетка, по которой идут; растущий фрактал; траектория полёта).
Тест: «если сцену можно заменить стоковым фото — переделай».
**Признаки:** **сквозной объект** во всех главах (красная нить → ходит по улицам → становится звуковой волной → рисует
колам → летит по траектории); название — одно слово на языке предмета со словарной сноской («сутра (сущ.) 1. нить
2. правило 3. то, что держит вместе»); 6–10 глав; печатный HUD (метки приводки, плашки красок, «ПЛАСТИНА 03 / 08»,
номер главы в древней системе счисления, бегущий год, нить прогресса с бусинами глав); несовмещение ризографа на
героях (сдвиг 4–7 px, новый каждые 3 кадра); полутон; гигантские вертикальные слова; текст по кругу (печать);
пишущая машинка; ступенчатые/ирис-вайпы в две краски; глитч на стыках **вместе со звуковым статтером**; белая вспышка на дропе.
**Палитра:** бумага + ночь + 5 красок, названных материалами культуры (Индия: индиго, синдур, халди, рани, мор;
Япония: суми, сю, ай, кинча, матча; космос: vantablack, натриевый оранжевый, H-alpha красный, OIII бирюза).
Светлые и тёмные главы чередуются; в дроп-главе палитра меняется каждый такт.
**Тайминг в долях:** 90–110 BPM, глава 8–16 долей. Кривая энергии: тихое интро → рост → **вдох** (осциллограф
настоящего саундтрека + коса слов) → рост → **ДРОП на самой неожиданной идее** → половинный темп → финальный удар →
тихая рамка (главы-бусины на нити, возврат к первому образу). Тихаи (фраза ×3) точно приземляется на склейку.
**Никогда:** центрированная карточка-заголовок с фейдом; градиенты/свечение/блики как декор; эмодзи; реальные лица и
логотипы; флаги как украшение; стереотипные образы. Все даты/числа проверены; неуверенно — «ок.», схемы — «схематично».
**Звук:** музыка пишется **первой**; лад и инструменты под культуру (рага + танпура + ситарный щипок с глиссандо;
in-sen + чистый щипок + колокола; хиджаз + рамочный барабан); «у каждого визуального события есть звук»; сайдчейн
от бочки 70 %. Осциллограф/реакция на звук — из огибающей нашего же микса (см. `sound.md`).

## 26. Study model / Teardown — 3D-разбор механизма
**Источник:** teardown (MIT). Полный метод — `simulators.md` (маршрут E).
**Признаки:** светлая студия, мягкие тени на невидимом полу, машина занимает 60–70 % окна; **один акцент** — деталь,
которая работает сейчас; стеклянные гильзы, разрез, рентген, exploded view; консоль 1600×900 вокруг: крупное живое
число слева сверху, графики, которые движутся вместе с механизмом (PV-петля, подъём клапана), 2D-схема из той же
модели, выноски с тонкими линиями; кнопка на подсистему; автотур курсором.
**Техники:** всё — функции **одного входа** (угол коленвала, ход, ветер) в реальных единицах; металл roughness ≥ 0,45,
envMapIntensity ≈ 0,5; почти-белым деталям — чернильный контур; камера 3/4 для плоских механизмов; коллизии — числом.
Входы `cubic-bezier(0.16,1,0.3,1)`, выходы `cubic-bezier(0.6,0,0.9,0.35)` вдвое короче; подписи ≥ 34 px на 1080.
**Звук:** аккордовый бед (Am9, 92 BPM), мягкий «тук» на каждом рабочем ходе, тихий клик на кнопку, воздух под перетаскиванием.

## 27. 3D-титры вокруг спикера — Camera-3D Captions
**Источник:** HyperFrames `camera-3d-captions` (Apache-2.0). Для говорящей головы со статичной камерой.
**Признаки:** слова висят в 3D-пространстве вокруг человека: группы глубины, кольцо слов перед спикером, главное
слово **за головой** (через альфа-маску человека), пролёты камеры сквозь слова, «лестница» в финале.
**Техники:** плейт расширен отражением (+240 px по бокам, +480 сверху, +240 снизу), чтобы рывки камеры не показывали
край; маска человека — локальная модель удаления фона; проекция `screen = C + (ref − C)·D0/(D0 − cz)`, фокус
`F = 1326,1·H/1080`; группы глубины D 1250 / 1500 / 2200 (плейт 3000); кольцо: центр Z 2000, R 760, наклон 11–16°;
**текст постеризован до 15 fps** + motion blur из 7 «призраков» на половине шага; **титры опережают голос на 0,2 с**
по 15-fps сетке: `fr(t) = 2·round((t − 0.2)·15)`; ГРИП `σ = 6,7·|D − focus|/D` px (плоские титры ≤ 1,2 px); тень глубины
масштабируется `1500/(D − cz)`; подъём входа 30 px у титров, 110–260 px у героев (таблица остатка
`[1,.564,.342,.188,.139,.09,.06,.035,.02,.002,0]`); титры — над тёмной частью кадра; без финальных точек.
**Проверки:** ни одна группа не за кадром ≥ 5 шагов; слова не касаются друг друга; зазор ≈ ширине пробела.

## 28. Акварель и письмо кистью — p5.brush Paint & Handwriting
**Источник:** HyperFrames `p5-paint-animation` (Apache-2.0; p5 — LGPL, p5.brush — MIT).
**Три потока:** (A) **рукописное появление текста** — перо пишет фразу кистью `2B`/`crayon`/`charcoal`, камера идёт
за пером в посте (рендер широкий 4800×1350, окно 1200×675, `cx += (pen.x + 100 − cx)·0.14`, **y зафиксирован по
базовой линии**), слова стартуют в момент произнесения, крупные слова въезжают `1 − 2^(−9t)` ~0,65 с с направленным
смазом 3–7 копий; (B) **фото → живопись** (пастель / гуашь / уголь; кадрируй по объекту — «размер лица в кадре решает
всё»; мазки от крупного к мелкому, спокойные зоны первыми, лицо последним, затем косинусный отъезд ~28 кадров);
(C) **видео → живая картина**: решётка мазков строится по первому кадру и **фиксируется** (меняются только цвета и
направления — без «кипения»), 12 fps; тёмный футаж — только гамма (`eq=gamma=1.2`), никогда насыщенность.
**Подходит:** к стилям 21 (тушь) и 22 (аниме-опенинг) — оживить арты персонажей как живопись.
