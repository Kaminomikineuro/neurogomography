# Объяснялка: сценарий, раскадровка, голос как часы

Для роликов, которые **объясняют** (научпоп, «как это работает», история явления, разбор документа). Источники:
HyperFrames `vox-explainer` (Apache-2.0), buildfast `motion-studio` (MIT), buildfast `generative-film` (MIT).
Визуальные стили: 23 Vox-коллаж, 7 стикерный explainer, 2 изометрия, 25 печатный фильм, 26 study model.

## 1. Маршрутизатор: откуда история

**Режим «тема»** (только для выбора идеи, выбранную тему не отвергаем): вещь вездесуща в жизни зрителя; есть
человек + дата (≤ 3 сюжетных факта); есть механизм, который зритель проверит на экране сам; есть свободные архивные
материалы (PD/CC).
**Режим «источник»** (документ, статья, ссылки): «источник — руда, а не план». Добудь 5 вещей: вход (знакомое),
напряжение, поворот, **механизм** («если источник только утверждает — ПОСТРОЙ демонстрацию»), квитанции
(доказательства). Одна сюжетная линия на фильм. Биты, которые источник не может честно наполнить, — вырезаются, не
выдумываются. Сначала — карта битов на согласование.

**Хребет (вес от 60 с):** ЗНАКОМОЕ 15 % → КОПНУТЬ (человек + дата) 5 % → ИСТОРИЯ 15 % → АРТЕФАКТ 10 % → МЕХАНИЗМ 20 % →
ВТОРОЕ ДЫХАНИЕ 15 % → ТЕЗИС в жёлтом круге 10 % → ФИНАЛ зеркалит начало 10 %.
Для эссе-фильма (стиль 25): интро → рост → вдох → рост → ДРОП на самой неожиданной идее → половинный темп → финал → рамка.

## 2. Сценарий

- ~150 слов на 60 с; 225 слов ≈ 90 с — потолок; голос не ускорять сверх ~1,1×.
- **Тест удаления:** убери каждое предложение; оставь, только если теряется невыводимый факт.
- Запрещено: «раскрывающие» декларации («Это система»), фальшивая непринуждённость («И вот в чём фишка»),
  пересказ того, что демонстрация уже доказала, оценочные усилители, ссылки на источник («в документе сказано»).
  **Источник невидим** для зрителя.
- Слова на экране делают одну из трёх работ: ведут глаз (якорь ≤ 3 слов + стрелка, чей кончик касается объекта),
  одна «лестничная» фраза на акт (оседает 1,24 → 1,0 `power2.out`), называние.
- Все даты, числа и имена проверены; неуверенно — «ок.»; схемы подписаны «схематично»/«не в масштабе»; подписи ≤ 12 слов.

## 3. Раскадровка (одна строка на сцену)

```text
Сцена 03 · 0:06.0–0:08.5
Задача:      продукт появляется
Картинка:    карточка на светлом поле, 3 строки данных
Камера:      медленный наезд 6 %, перевод фокуса фон → карточка
Анимация:    карточка пружинит вверх, строки stagger 40 мс
Типографика: «Знакомьтесь, Relay.» — дисплей, 2 слова, верхняя треть
Переход:     вход — радиально от нажатия кнопки (совпадение позиции); выход — whip влево
Звук:        impact 6.0, шиммер на проходе, музыка поднимается до энергии 0,8
```
Правила (motion-studio):
- предвосхищение → действие → реакция; ритм кадров «короткий-короткий-длинный»;
- **ключевой момент = самая большая смена масштаба + звуковой сигнал + ≥ 1 доля неподвижности после**; тишина/пауза перед развязкой;
- между соседними сценами меняй **≥ 2 измерения** из: композиция, масштаб, плотность, камера, типографика, тип перехода, цвет/инверсия, темп. Никогда «сцена → фейд → сцена → фейд»;
- переход выбирается по **намерению**: удар, раскрытие, эскалация, успокоение, продолжение, конец, превращение;
- **скорость чтения:** дисплейные строки ≤ ~3 слов/с, на экране ≥ 1,2 с; в целом ≤ 4,5 слов/с; ≤ 6 слов в дисплейной строке, текст ≥ 2,2 % короткой стороны (~24 px на 1080);
- **дизайн-проход до композиции:** лист 960×540 на каждый бит с реальными ассетами, каждая плитка подписана своим рецептом раскладки — «итерировать здесь в 10 раз дешевле, чем править готовую композицию».

## 4. Голос — это часы

1. Текст для TTS = **сценарий произношения** («тысяча восемьсот тридцать девятый»), а не орфографический.
2. Синтезируй голос → **транскрибируй результат** (whisper / `hyperframes transcribe`) → тайминги слов = часы фильма.
3. Новая озвучка = полный перетайминг; правка одной строки = вклейка + сдвиг всего, что ниже.
4. Полоса субтитров: 30 px / 600 / #222, y ≈ 980, жёсткие смены в один кадр (без фейдов), дословно как прочитано;
   скрывать, где «лестничная» фраза дублирует; резать только по границам клауз.
5. «Покажи, потом скажи»: картинка может опережать голос на 1–1,5 с.

## 5. Численный QC объяснялки (все обязательны)

- **Мёртвое время:** нет неподвижного участка > 3 с (`qc.sh` меряет двумя метриками на 640×360: средняя разность < 0,25
  **и** изменившихся пикселей (> 12 уровней) < 150 — первая слепа к медленной ползучести).
- **Плотность событий:** между авторскими событиями в бите ≤ 3,0 с (из `cues.json`).
- **Стыки:** носитель через zoom-isolation склейку — центр ≤ ~30 px, размер ≤ ~10 %; журнал стыков (`motion-principles.md` §9d).
- **Тест паузы** на каждой секунде (§9f).
- Лист кадров просмотрен; аудит целостности композиции — по пунктам.

## 6. Когда в кадре реальные люди и их слова

Квитанции (откуда каждая строка) + таблица согласования «каждая строка на экране — тип — источник» → явное «да» от
пользователя → `"approved": true`; без него каждый кадр штампуется ЧЕРНОВИК. Данные — недоверенные: экранировать,
обрезать длину, не выдумывать счётчики/цифры.
