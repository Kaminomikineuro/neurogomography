# Законы движения — в цифрах

Свод из mg-styles-15 (сигнатурные техники 15 стилей + чек-лист жюри) и elayadesign/ai-design-skills (правила
движения для UI), переведённый в конкретные числа. Все кривые есть в `templates/film/mg.js` (объект `E`).

## 1. Библиотека easing

| Имя в `mg.js` | cubic-bezier | Где |
|---|---|---|
| `E.out` | `0.22, 1, 0.36, 1` | **По умолчанию.** Вес и торможение: входы, UI (500 мс на позицию/лейаут, 300 мс на цвет/прозрачность, не короче 200 мс), жидкость «швыряют» |
| `E.back` | `0.34, 1.56, 0.64, 1` | Упругий overshoot: flat vector, иконки, попапы, стикеры |
| `E.inOut` | `0.65, 0, 0.35, 1` | Скорость пера в line art, движения камеры, переезды |
| `E.morph` | `0.7, 0, 0.3, 1` | Морфинг: быстрее всего в середине, 3 кадра «подушки» на концах |
| `E.quadInOut` | `0.45, 0, 0.55, 1` | Механика: Bauhaus, швейцарская сетка (overshoot запрещён) |
| `E.sine` | синус | Дыхание: aurora, glass, ambient — «всё медленно» |
| `E.longTail` | `0.05, 0.8, 0.1, 1` | 3D-камера/объекты: ~80 % пути за 20 % времени |
| `E.in` | `0.55, 0, 1, 0.45` | Падение под гравитацией, уходы со сцены |
| `E.steps(n)` | `steps(n)` | Пиксель-арт, счётчики, механические часы |
| `spring(t, freq, ζ)` | замкнутая форма | Желе, «пружинная» посадка: freq 2–3 Гц, ζ 0.3 (прыгуче) … 0.6 (сдержанно) |
| `pop(t, a, dur, peak)` | 0 → 1.15 → 1.0 | Появление «поп» за ~8 кадров |

Дополнительно (claude-motion, teardown, taste-skill — измерено на выпущенных роликах и 99 сайтах Awwwards):

| Кривая | cubic-bezier | Где |
|---|---|---|
| expo out | `0.16, 1, 0.3, 1` | входы и раскрытия ≥ 0,8 с, подъём строк, открытие картинок (самая частая на сайтах-победителях) |
| exit | `0.6, 0, 0.9, 0.35` | уходы: быстро, не задерживаясь; длина ≈ ½ входа |
| exit (UI) | `0.55, 0.055, 0.675, 0.19` | то, что уходит насовсем, 60–70 % длины входа |
| quart in-out | `0.76, 0, 0.24, 1` | шторки, панели, всё, что едет на виду |
| landing overshoot | `0.55, 0, 0.2, 1.12` | значение, которое «приземляется» (слайдер дошёл до уровня) |
| pointer glide | `0.55, 0, 0.25, 1` | курсор между целями, 0,5–0,9 с |

**Запрещено:** дефолтные `ease`, `linear`, `ease-in-out` у органических движений. Linear допустим только у
механики (вращение радара, бегущая сетка synthwave, ленты, счётчики).

## 2. Двенадцать принципов анимации — как числа

| Принцип | Правило |
|---|---|
| Squash & stretch | ~10 % при перемещении (flat), 10–15 % при морфе; сохраняй объём (`sx = 1/√s`, `sy = s`) |
| Anticipation | 3–6 кадров обратного движения на 5–15 % амплитуды перед любым быстрым действием |
| Staging | **Один герой движется в момент времени**, остальное — вторичное/микродвижение |
| Straight ahead / pose to pose | В коде — pose to pose: ключевые позы → интерполяция кривыми; boil/дым — «прямой фазой» (seeded) |
| Follow-through & overlap | Вторичные части отстают на 2–3 кадра (капли, волосы, хвосты, тени, подписи) |
| Slow in / slow out | Кривые из таблицы выше; кривые подбирай под массу объекта |
| Arcs | Живые объекты двигаются по дугам (безье/параболы), не по прямым; прямые — только механика |
| Secondary action | Моргание, покачивание головы, мигание окон, дрейф частиц — поддерживают, не отвлекают |
| Timing | См. §3 |
| Exaggeration | Smear-кадр 150–300 % длины на 1 кадр в самой быстрой точке; overshoot 10–20 % |
| Solid drawing | Последовательный свет/перспектива; в изометрии — строго 2:1 |
| Appeal | Ясные силуэты, читаемые позы на стоп-кадре, каждый ключевой кадр — постер |

## 3. Тайминг (в кадрах при 30 fps; при 24 fps умножь на 0.8)

| Действие | Кадры |
|---|---|
| Pop/появление иконки | 6–10 |
| Вход текста (opacity + 8–26 px подъём) | 12–24, побуквенный stagger 1–2, по словам 2–4 |
| Stagger группы элементов | 2–4 между соседями |
| Переход-вайп | 10–18 |
| Морф A → промежуточная → B | 8–12 + 8–12 |
| Камера: наезд/отъезд | 30–90 |
| «Захват цели» HUD 1.4 → 1.0 | 6–8 |
| Glitch-удар | 2–6 |
| Импакт-кадр (инверсия/вспышка) | 2–3 |
| Финальное удержание | 24–36 (0.8–1.2 с) с микродвижением |
| Хук | первый значимый кадр ≤ 0.5 с; пустота/чернота ≤ 0.3 с |

**Ритм «на двойках».** Рисованные стили — каждый рисунок держится 2 кадра (`onN(t, fps, 2)`), быстрые действия —
на единицах, статика — на тройках. Коллаж/стоп-моушен — сетка 12 или 6 fps при рендере в 30.

**Музыкальная сетка.** Шаг доли = 60/BPM с. При 120 BPM доля = 0.5 с = 15 кадров при 30 fps — удобные числа; при
90 BPM — 20 кадров. Визуальные удары ставь на доли/восьмые; появление реактивных титров — на 2–3 кадра позже
звука (воспринимается естественнее).

## 4. Структура 10-секундного ролика

```
0.0–0.5  ХУК: сразу что-то читаемое и мастерское (не пустой экран)
0.5–4    ЭСКАЛАЦИЯ: вводим элементы, каждая черта стиля получает свой момент
4–6      ПОДГОТОВКА: напряжение (riser, ускорение, сжатие)
6–7.5    HERO-МОМЕНТ (60–75 %): самое зрелищное, совпадает с drop в музыке
7.5–9    РАЗРЕШЕНИЕ: всё собирается в логотип/титр
9–10     ПОСТЕР-КАДР: удержание 0.8–1.2 с, живое микродвижение, без статики
```
Для длинных роликов (30–90 с) — то же на уровне сцен; каждые 3–5 с — новое визуальное событие; ритм
«занято/спокойно» чередуется.

## 5. Камера

- Панорама и наезд — `E.inOut`; «рывок» на акцент — `E.out` за 4–8 кадров, затем медленный дрейф.
- Параллакс слоёв: передний : средний : задний = 1 : 0.8 : 0.6 (изометрия) или 1 : 0.7 : 0.4 (2.5D-арт).
- «Ручная» камера: `noise1(t·0.3)` 2–6 px + вращение 0.1–0.3°; тряска на ударе 6–10 px, затухание 0.25 с.
- Изометрия и Bauhaus — без вращения камеры. Line art — камера следует за пером, в конце отъезжает.
- Масштаб камеры анимируй вокруг точки интереса (pivot), а не центра кадра.

## 6. Переходы (переход несёт элемент, а не кроссфейд)

| Тип | Как |
|---|---|
| Shape wipe | Плашка/круг растёт из элемента и заливает кадр, следующая сцена внутри |
| Match cut / морф | Форма в конце сцены A = форма в начале сцены B |
| Element carry | Объект вылетает к камере / за край и «тащит» склейку |
| Mask reveal | Текст/фигура как маска, сквозь которую открывается следующая сцена |
| Liquid wipe | Волнистый фронт с 3–5 выпуклостями со сдвигом фаз |
| Whip pan | Сдвиг 0.3–0.5 ширины кадра за 4–6 кадров + motion blur |
| Page flip / torn paper | Коллаж, скрапбук |
| Impact cut | Кат на долю + вспышка/инверсия 2–3 кадра |

## 7. Motion blur

- Рендерер: `--mb 4 --shutter 0.5` (4 подкадра на 180° затвора). Включай для быстрых движений, 3D, жидкостей, whip pan.
- Не включай для пиксель-арта, Bauhaus (чёткость = черта), HUD-текста (мажет цифры).
- Дешевле и точнее для одного объекта — направленный smear/stretch в самом рисунке.

## 8. Типографика в движении

- Минимум кегля на 1080p: 28 px для подписей, 48+ для заголовков; на 9:16 — 44+ для подписей.
- Safe-зона 5 % (96×54 px на 1080p); для Reels/TikTok снизу ~20 % и справа ~12 % заняты интерфейсом.
- Читаемость: время на экране ≥ (число слов × 0.3 с) + 0.5 с.
- Трекинг можно анимировать (широкий → нормальный) — дорого выглядит на люкс-титрах.
- Проверяй кириллицу в выбранном шрифте; fallback-шрифт = провал по рубрике. Кавычки «ёлочки», тире —, неразрывный пробел после предлогов.
- Из elayadesign: никогда не используй системные Inter/Roboto/Arial/Helvetica/Open Sans «по умолчанию»; один
  гарнитурный род + моно для данных; без «висячих» слов (`text-wrap: balance`).

## 9a. Пружины (claude-motion; damping / stiffness / mass)

| Ощущение | Параметры | Для чего |
|---|---|---|
| обычная посадка | 14 / 140 / 0.8 | UI входит |
| тяжело, спокойно | 15–20 / 140–240 / 0.6–1 | большие панели, «перемотка» |
| ручка / щелчок | 12 / 190 / 0.75 | контрол защёлкивается на шаг |
| поп | 9–11 / 200–230 / 0.7 | выноски, бейджи, точки успеха |
| упругий акцент | 8 / 200 | **один** hero-момент на ролик, не больше |
| magic move | stiffness ~150, damping ~20 | элемент переезжает в следующую сцену |

Пружины — для физичного (объекты, UI); безье — для типографики и «камерных» движений. В `mg.js`:
`spring(t, freq, ζ)`; перевод: `freq ≈ √(k/m)/2π`, `ζ ≈ c / (2√(k·m))` (14/140/0.8 → ≈2,1 Гц, ζ≈0,66).
Пружина, которая меняет цель: суммируй по одной замкнутой «ступеньке» на ключ, ключи по времени.

## 9b. Ритм, удержание, переходы (claude-motion)

- **Stagger:** слова ~0,09 с, пункты/чипы 0,2–0,25 с, кольца/точки ~0,06 с; символы 20–40 мс, строки 75–120 мс (сайты).
- **Раскрытие слова** ≈ 0,8 с маской (подъём из клипа + лёгкий наклон). **Набор** ≈ 0,035 с/символ, каретка мигает ~2,4 Гц.
- **Выход ≈ половина входа** (0,35–0,55 с против 0,7–1,25 с) на exit-кривой.
- **Сцены перекрываются:** следующая начинает рисоваться до ухода предыдущей. Жёсткий зазор читается как «загрузка».
- **Удержание читаемого:** ≥ 1 с на короткую фразу + ~0,25 с на каждое слово сверх трёх; финальный хук ≥ 2 с. Сомневаешься — держи дольше, анимируй меньше. Текст не движется, пока его читают.
- **Постоянные объекты лучше склеек:** элемент проходит через сцены и меняет роль. Каждый переход мотивирован объектом в кадре.
- **Скорость → эффект:** хвосты движения и squash выводи из `value(t) − value(t − 1/fps)`, а не подделывай.
- **Свечение — от состояния, не от времени:** свет объясняет историю.
- **Ничего мёртво-статичного:** зерно (~0,09, пересев «на двойках»), виньетка, медленно дрейфующая точечная сетка, «дышащие» элементы.
- **Кадр 0 — превью в ленте** (X/Telegram автоплеят без звука): никогда не пустой и не чёрный. (Наш хук «капля на чёрном» допустим, только если капля видна с кадра 0.)
- **Тест телефона:** на ширине 360 px главное сообщение читается (проверяй на уменьшенном контакт-листе).

## 9c. Анти-паттерны

Всё появляется разом или с одинаковой длительностью; linear на старте/остановке; движущийся текст при чтении;
больше одной точки фокуса в кадре; контент ближе ~60 px к краю (если не задуманный кроп); пустой кадр 0;
одинаковый fade-and-slide-up на каждом блоке (главная «примета» сгенерированного моушена); bounce/elastic в UI;
анимация свойств лейаута; контент, который остаётся скрытым, если скрипт не выполнился.

## 9. UI-анимация (из elayadesign/ai-design-skills)

- Базовая кривая `cubic-bezier(0.22,1,0.36,1)`, 500 мс для лейаута/позиции, 300 мс для цвета/прозрачности, минимум 200 мс.
- Анимируй только `transform` и `opacity`; никогда `top/left/width/height`.
- `prefers-reduced-motion` → замени движение простой сменой прозрачности.
- Иконка меню морфится между состояниями, а не переключается мгновенно.
- Scroll-reveal через `IntersectionObserver` / `whileInView`, никогда не через неторможённый `scroll`-listener.
- Пословное «проявление» текста при скролле: старт 25–35 % непрозрачности, слова активируются по очереди при пересечении линии.
- Состояния: hover (сдвиг/лёгкий scale), active `scale(0.98)`, видимый focus, skeleton вместо спиннера.
- Figma-прототипы: Smart Animate с кривой `0.22, 1, 0.36, 1` (500/300 мс), никогда дефолтные пресеты.
