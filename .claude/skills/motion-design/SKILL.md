# Motion Design — единый скилл

Задача: на выходе — **готовый ролик уровня студии** (Buck, ManvsMachine, Territory, Apple keynote), а не «шаблон из
After Effects». Чистый, но безликий результат = провал.

Скилл собран из пяти источников (см. `references/sources.md`): 15 стилей и пайплайн рендера из **mg-styles-15**,
визуальная система и правила движения из **elayadesign/ai-design-skills**, просмотр видео из **claude-video (/watch)**,
генерация видео нейросетями через **polza.ai**, библиотеки промптов для web-motion (**prompt-motion** и аналоги).

## 0. Выбор маршрута (сначала это)

| Что просят | Маршрут | Читать |
|---|---|---|
| Ролик/интро/титры/логотип, графика, инфографика, типографика | **A. Код → MP4** (основной) | `references/styles.md`, `references/pipeline.md` |
| «Оживить» арт/персонажа, кинематографичный кадр, живое видео, фотореализм | **B. Видеонейросеть** (Veo/Kling/Seedance/Sora) | `references/ai-video-generation.md` |
| Анимация в интерфейсе, лендинге, скролле, 3D-сайт | **C. Web-motion** | `references/web-motion.md` |
| «Посмотри этот ролик / сделай как здесь» | **D. Разбор референса** → затем A/B/C | `references/reference-analysis.md` |
| Комбо: нейросеть-футаж + MG-графика поверх | **B → A** (футаж как слой в HTML) | оба |

Маршрут A детерминирован, даёт идеальную типографику и точный тайминг. Маршрут B даёт «живую» картинку, но текст,
логотипы и точный тайминг у нейросетей плохие — их всегда доделывай маршрутом A поверх.

## 1. Бриф (≤ 5 вопросов, только если ответа нет в запросе)

1. Что за ролик и где покажут (формат: 16:9 1920×1080, 9:16 1080×1920, 1:1 1080×1080, 4:5 1080×1350).
2. Длительность (по умолчанию 10 с; соцсети 6–15 с; интро 3–5 с; explainer 30–90 с).
3. Стиль — предложи 2–3 из `references/styles.md`, которые подходят к задаче, с одной фразой «почему».
4. Тексты/бренд/цвета/шрифты, ассеты пользователя (в этом репозитории: арты персонажей в `Аниме/`).
5. Звук: нужен ли, жанр, есть ли своя музыка/голос.

Если пользователь сказал «сделай сам» — выбирай сам и фиксируй решения в отчёте.

## 2. Пайплайн маршрута A (код → MP4)

Повторяет процесс, которым сделаны все 15 фильмов mg-styles-15 (оценки жюри 7.6–8.2/10).

1. **Treatment.** Одна ясная идея. Хук в первые 0.5 с (никогда не начинай с > 0.3 с пустоты/черноты), эскалация,
   **один безошибочный hero-момент на 60–75 % хронометража**, финальный кадр-постер, удерживаемый 0.8–1.2 с с живым
   микродвижением. Каждой «сигнатурной черте» стиля — свой момент.
2. **Cue sheet.** Один `cues.json` (секунды битов, BPM, drop, outro, список SFX), из которого читают **и картинка,
   и звук**. Шаблон: `templates/film/cues.json`.
3. **Ключевые кадры до движения.** Собери лук, отрендерь 6–10 стоп-кадров (`--stills`) и **посмотри на них** (Read
   PNG). Каждый — постер: композиция, иерархия, негативное пространство, кернинг, safe-зона ~5 %. Итерируй, пока
   ничего не выглядит дефолтным, тесным или «AI-шаблонным».
4. **Движение.** Хореография по законам из `references/motion-principles.md`. Превью в низком разрешении
   (`--scale 0.5`), пошагово проверь самые быстрые движения: spacing, easing, дуги, overlap, anticipation,
   follow-through, motion blur. Никаких непреднамеренных мёртвых участков.
5. **Звук.** Жанрово-верная музыка + SFX по тому же cue sheet (`references/sound.md`, `scripts/audio_kit.py`).
   Визуальные удары = онсеты звука. Мастер: −14 LUFS integrated, true peak ≤ −1 dBTP.
6. **Финальный рендер** (`scripts/render.mjs`, motion blur где уместно) → **QC** (`scripts/qc.sh`): точная
   длительность, разрешение, fps, звук и громкость, нет чёрных кадров, нет fallback-шрифтов/«тофу», ничего не
   обрезано краями, нет мерцания тонких линий и бандинга градиентов. Смотри contact sheet глазами.
7. **Самооценка по рубрике** (`references/review-rubric.md`), 1–10 по 7 осям. Цель — 9. Чини самую слабую ось
   первой. Для важных работ — независимое ревью вторым агентом (Agent tool) и ещё один круг правок.

Стартовый проект — `templates/film/` (рабочее демо в стиле Line Art: заставка «Хроники рода Эльтар — Белая
кровь»; `index.html` с контрактом `renderAt`, `mg.js` с кривыми/пружинами/seeded random, `cues.json`). Скопируй и
перепиши под задачу:

```bash
SK=.claude/skills/motion-design
mkdir -p motion && cp -r $SK/templates/film motion/<slug>
node $SK/scripts/render.mjs motion/<slug> --stills 0.5,2,5,7,9.5        # стоп-кадры → out/stills/
node $SK/scripts/render.mjs motion/<slug> --scale 0.5 --noaudio          # быстрое превью
python3 $SK/scripts/audio_kit.py motion/<slug>/cues.json motion/<slug>/out/audio.wav
node $SK/scripts/render.mjs motion/<slug> --mb 4                         # финал с motion blur + звук
bash $SK/scripts/qc.sh motion/<slug>/out/video.mp4 10                    # проверки + contact sheet
```

## 3. Железные правила

**Детерминизм.** Каждый кадр — чистая функция времени `t`: `window.renderAt(t)`. Только seeded random
(`mulberry32`), физика и частицы — в замкнутой форме или предрассчитаны, никаких `Date.now()`,
`requestAnimationFrame`-состояния, CSS-transition по событиям. Повторный рендер = тот же файл.

**Движение** (свод из mg-styles-15 и elayadesign):
- Никогда не используй дефолтные кривые (`ease`, `linear`, `ease-in-out`), кроме намеренно механических стилей
  (Bauhaus, HUD-счётчики, пиксель-арт со `steps()`).
- Базовые кривые: выход/торможение `cubic-bezier(0.22,1,0.36,1)`; упругий overshoot
  `cubic-bezier(0.34,1.56,0.64,1)`; плавный in-out `cubic-bezier(0.65,0,0.35,1)`; морфинг
  `cubic-bezier(0.7,0,0.3,1)`; 3D «длинный хвост» — 80 % пути за первые 20 % времени.
- Вход: anticipation → выброс → overshoot → settle. Stagger 2–4 кадра. **Один герой движется в момент времени.**
- Squash & stretch ~10 % (морфинг 10–15 %, smear-кадр 150–300 % на 1 кадр).
- Переходы несут элементы (shape wipe, объект вылетает и «тащит» склейку), а не кроссфейд.
- В UI анимируй только `transform` и `opacity`; уважай `prefers-reduced-motion`.

**Дизайн:** 3–6 конкретных HEX-цветов на ролик; один гарнитурный род + моно для данных; никаких Inter/Roboto/Arial
по умолчанию; никаких «висячих» слов; текст ≥ 5 % от краёв; на кириллице — проверяй, что шрифт содержит глифы
(иначе fallback = провал по рубрике).

**Контент:** выдуманные бренды вместо реальных товарных знаков; не выдумывай факты/цифры для реального продукта —
ставь `{{placeholder}}`; без слов-пустышек («революционный», «новый уровень», «мощь»). Тексты на русском —
естественные, с правильной типографикой («ёлочки», тире —, неразрывные пробелы перед коротким словом).

**Ассеты:** только CC0 / public domain / OFL / Apache / разрешённые для коммерции. Источник и лицензию каждого —
в `CREDITS.md` рядом с роликом.

## 5. Отчёт пользователю (всегда)

`video.mp4` (+ стоп-кадр-постер) и короткий отчёт: идея в двух предложениях; beat sheet с таймкодами; как
реализована каждая сигнатурная черта стиля; технический маршрут; цифры QC (длительность, разрешение, fps, LUFS,
true peak); честные топ-3 слабости и что сделать с ещё одним кругом.
