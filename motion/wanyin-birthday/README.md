# «Письмо из Облачных Глубин» — Цзян Ваньиню, с днём рождения

**Ровно 2:08** (128 с, 3072 кадра) · 1920×1080 · 24 fps · стиль 21 «Тушь / свиток» из скилла `motion-design`.

Письмо Лань Сичэня мужу, написанное тушью на одном длинном свитке. 8 секунд пролога + 8 сцен по 15 секунд.
Камера едет вдоль свитка, картины разделены туманом, а письмо пишется кистью от руки в пустом небе каждой
картины и заверяется красной печатью «Л». В финале свиток сворачивается обратно в валик, и на последних
секундах на тёмном листе проступает печать **«02:08»** — ровно когда заканчивается ролик.

| Время | Картина | Что происходит |
|---|---|---|

| 0:08–0:23 | Пристань Лотоса | пагода, пирс, фиолетовые знамёна Юньмэна на ветру, Ваньинь смотрит на пруд, лотосы раскрываются |
| 0:23–0:38 | лунный мост | двое на мосту; на «Я знаю» Ваньинь оборачивается; на «и под каждой нашёл тепло» под каждым шипом ветки раскрывается цветок сливы |
| 0:38–0:53 | мелочи | свитшот с сердечком, носочки; булавки падают с подола его одежды и одна за другой прыгают в лаковую шкатулку, крышка закрывается; сердечко бьётся на «ворча» |
| 0:53–1:08 | Хэллоуин | луна, летучие мыши, чаепитие и тыквы; сначала появляется только улыбка, потом весь чеширский кот (с серебряным колокольчиком на ошейнике); шляпник чешет его за ушком — кот жмурится и мурчит |

| 1:38–1:53 | слияние | облака Гусу плывут над лотосами Юньмэна; на облаке раскрывается лотос; лодка с двумя плывёт к горам |
| 1:53–2:08 | приз | полная луна над пирсом, фонарики на воде и в небе; «Вот он» — камера отъезжает, виден весь свиток с валиком; свиток сворачивается; лотос, «С днём рождения, Цзян Ваньинь. Я люблю тебя.», удар печати «02:08» |

**Палитра:** рисовая бумага #F2EBDD, тушь #1C1A21, фиолетовый Юньмэна #6B3FA0, сине-белый Гусу #5E7FA8 / #DDE6EF,
киноварь печатей #B8322A, золото огней #E2B04B, ночь #241F2E.
**Шрифты:** Marck Script (письмо от руки), Cormorant Garamond (имя). Оба — OFL, с кириллицей.
**Звук:** сяо (флейта Сичэня) поверх гучжэна и мягкого пэда в пентатонике ре; на Хэллоуин гучжэн сменяется
пипой; бумага, шорох кисти, печати, капля, стук поезда, мурчание, сердцебиение в момент, когда руки встречаются;
финальная печать — удар. −14 LUFS. Голос можно добавить — см. [VOICE.md](VOICE.md).

Персонажи нарисованы в традиции тушевой живописи — без лиц, силуэтами в одеждах своих кланов.

```bash
MGAUDIO=<mg-styles-15>/lib/audio python3 motion/wanyin-birthday/audio.py
node .claude/skills/motion-design/scripts/render.mjs motion/wanyin-birthday --workers 4 --crf 18 --out motion/wanyin-birthday/out/wanyin-birthday.mp4
bash .claude/skills/motion-design/scripts/qc.sh motion/wanyin-birthday/out/wanyin-birthday.mp4 128 1920x1080 24
```

Файлы: `index.html` (камера-свиток, пролог, финал, письмо), `scenes/sections.js` (8 картин), `lib/ink.js` (кисть,
размывы, горы, туман, печать, письмо от руки), `lib/figures.js` (Сичэнь, Ваньинь, чеширский кот, лотосы),
`cues.json` (единый таймлайн для картинки и звука), `audio.py`, `VOICE.md`.
