# «Посылка из 2036» — от Лань Сичэня Цзян Ваньиню

Интерактивная страница-посылка. Уведомление «Тебе пришла посылка» → крафтовая коробка с фиолетовой лентой и
наклейкой «Хрупкое: сердце» → внутри на фиолетовой бумаге 28 воспоминаний за десять лет (и ещё шесть мелочей на
дне). Каждую вещь можно достать, рассмотреть и вернуть в коробку; у каждой своё действие: карточку — перевернуть
(спереди цитата из Telegram, сзади «фото» и прикреплённое доказательство: трусики на прищепке, подкова-магнит,
вышитая ленточка), мешочек — потянуть за верёвочку, снежный шар — встряхнуть, банку из Праги — открыть
(предсказания из печенек), шкатулку — покрутить, рулетку — раскрутить, фонарь — включить, дневник — листать
(синие чернила — Сичэнь, фиолетовые — Ваньинь), банку поцелуев — досчитать до 288. Когда открыты все 28 —
финальная открытка и голосовое «Ты — моё всё» (голос из записи письма).

Цитаты — дословно из переписки; где сообщения не было — стикер-заметка. Звуки — WebAudio-синтез в странице.
Опубликовано как приватный Artifact; файл голоса — `voice-2036.mp3`.
