# «Приз за загадки» — интерактивная страница

Страница-квест: восемь загадок о вас двоих, каждая отгаданная открывает красную печать и превращается в купон
(«одно ворчание без последствий», «бесконечное чесание за ушком», «последний ролл — всегда твой» …). Седьмая — «твоё заветное желание» (я / ты / мы / мы вместе / Лань Сичэнь в любом написании),
восьмая, самая трудная — «где мы встретим Новый год» (в объятиях). Когда открыта восьмая печать — салют и «Ура!», через
две секунды на весь экран со звуком играет сюрприз (`surprise.mp4`), а после него открывается главный приз — премьера трейлера «Глава Цзян» и «итоги года» (письмо уже подарено).

Ответы хранятся хэшами (в исходнике их не подсмотреть). Слова проверяются по корню — «кот», «чешир», «объят», «обним»
и т. п., так что подходит любая форма («чеширским котиком», «в объятиях мужа»). Шифр «люблю тебя» принимает любой
китайский цифровой код со словом «люблю» (520, 5201314, 1314921, 200, 2013 …) и наш 0802. После двух ошибок —
подсказка; прогресс запоминается в браузере.

Видео для страницы (`trailer.mp4`, `wrapped.mp4`, постеры) собираются из `out/` роликов командой
`bash motion/wanyin-quest/build.sh` и публикуются вместе со страницей как Artifact (приватная ссылка).
