# «Приз за загадки» — интерактивная страница

Страница-квест: семь загадок о вас двоих, каждая отгаданная открывает красную печать и превращается в купон
(«одно ворчание без последствий», «бесконечное чесание за ушком», «последний ролл — всегда твой» …). Когда все
семь печатей открыты, разворачивается главный приз — видео-письмо и два бонуса (трейлер и «итоги года»).

Ответы хранятся хэшами (в исходнике их не подсмотреть), принимаются разные формы слова, после двух ошибок
появляется подсказка; прогресс запоминается в браузере. Загадку «Кто взял последний ролл?» решает любой ответ.

Видео для страницы (`letter.mp4`, `trailer.mp4`, `wrapped.mp4`, постеры) собираются из `out/` роликов командой
`bash motion/wanyin-quest/build.sh` и публикуются вместе со страницей как Artifact (приватная ссылка).
