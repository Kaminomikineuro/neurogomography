# КАК ОБНОВЛЯТЬ ВИКИ

Папка `wiki/` — справочник по актуальному тексту «Хроник рода Эльтар. Белая кровь». Собрана в октябре 2026 по Тому 1 (финал, в печати) и Тому 2 (каноническая редакция docx от 16 октября 2026, 36 глав; главы 22–30 переписаны, 31–36 новые). Том 3 не включён.

## Что здесь лежит

| Файл | Что это | Как обновлять |
|---|---|---|
| `BK_сюжет.md` | пересказ каждой главы | по главам |
| `BK_персонажи.md` | досье по людям | по главам → свести |
| `BK_мир.md` | локации, институты, обычаи, существа | по главам → свести |

Пометки: `(тT глN)` — ссылка на том и главу; `⚠ расхождение:` — главы противоречат; `⚠ в актуальном тексте не найдено` — было в старой версии или диктовка; `(КС — не сверялось)` — из «Культа Смерти»; `🆕` — добавлено при сверке.

## Сценарий 1. Переписана одна глава (самый частый)

1. Положить новый текст главы в файл `chapters/tT_NN.md` (заголовок `# Том T. Глава N. Название`).
2. Дать Claude задание из `_инструкции/ВЫПИСКА_главы.md` для этой главы → получить `extract/tT_NN.md` с пятью разделами.
3. В `BK_сюжет.md` и `BK_места_для_расширения.md` заменить раздел этой главы целиком.
4. В `BK_персонажи.md`, `BK_мир.md`, `BK_магия_и_предметы.md` — найти все строки с `(тT глN)`, удалить их и вставить факты из новой выписки под нужные сущности. Проще всего поручить это Claude: «вот старые файлы, вот новая выписка главы N, обнови ссылки на эту главу».
5. Проверить `00_расхождения` и `BK_открытые_крючки` — не закрыла ли правка что-то из них.

## Сценарий 2. Переписан целый том

1. Разложить том по главам в `chapters/`.
2. Запустить выписку (`_инструкции/ВЫПИСКА_главы.md`) по 3–5 глав на агента.
3. Склеить поглавные выписки по категориям, сгруппировать по сущностям, запустить сведение (`_инструкции/СВЕДЕНИЕ_досье.md`) по чанкам ~80 К символов.
4. Собрать итоговые файлы; собрать ⚠ в `00_расхождения`.
5. Сверить лор-файлы (`_инструкции/СВЕРКА_лор-файла.md`) — по одному файлу на агента.

Это ровно то, что было сделано в октябре 2026; стоимость — порядка 3–4 млн токенов на два тома.

## Сценарий 3. Появился Том 3

То же, что сценарий 2, плюс: в `_инструкции/СВЕРКА_лор-файла.md` обновить оглавления томов; в лор-файлах снять пометки `⏳ по старому Тому 2`, если материал теперь в тексте.

## Правила, которые нельзя нарушать

- Выписывать только то, что есть в тексте. Диктовки и планы — отдельно, с пометкой.
- Не менять «е»/«ё» в цитатах; в основном тексте романа «ё» не используется.
- Том 1 в печати — при расхождениях Т1 ↔ Т2 канон = Т1.
- Старую версию файла не удалять, а переносить в архив с датой.

## Сценарий 4. Автор прислала новый docx тома (как 16 октября 2026)

1. Извлечь текст из docx (стандартный `zipfile` + `xml.etree`, заголовки по стилю `Heading N`), разрезать на главы по «Глава N.».
2. Сравнить каждую главу с предыдущей версией (по абзацам / словам) — так видно, какие главы только с правками пунктуации (не трогать), какие переписаны (перевыписать заново) и какие новые.
3. Для переписанных и новых глав — выписка по `_инструкции/ВЫПИСКА_главы.md`; затем сгруппировать новые факты по сущностям и влить в досье (`BK_персонажи`, `BK_мир`, `BK_магия_и_предметы`), перепроверив старые факты со ссылками на переписанные главы (✏️ / ⚠).
4. Пересобрать `BK_сюжет.md` и `BK_места_для_расширения.md` для этих глав из выписок.
5. Лор-файлы, крючки, расхождения и ТЗ карт — сверка по `_инструкции/СВЕРКА_лор-файла.md` с добавлением 🆕 и снятием ⏳.
6. В каждом файле — раздел «ЖУРНАЛ СВЕРКИ (дата)».
