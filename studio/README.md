# Студия «Белая кровь»

Одно окно для всей работы над аниме: раскадровка по кадрам, референсы, промпты, генерация картинок через Кодекс, правки, версии и пакет для видео (Kling / Seedance / Pixverse).

```
Ты ──► Студия (браузер) ──► Кодекс рисует ──► картинка появляется в кадре
              │                                      │
              └── всё лежит в репозитории ◄──────────┘
                         │
                     Claude читает: канон, логика, промпты, журнал правок
```

## Запуск (Windows)

1. Один раз установи **Node.js** (https://nodejs.org, кнопка LTS).
2. Один раз поставь **Codex CLI** и войди своим аккаунтом ChatGPT. Открой «Терминал» и выполни:
   ```
   npm i -g @openai/codex
   codex login
   ```
3. Двойной клик по **`Студия.bat`** в корне репозитория. Откроется браузер с адресом http://localhost:4545.
   Чёрное окно не закрывай: это сервер студии.

Справа вверху должна гореть зелёная метка **«Кодекс на связи»**. Если она жёлтая, наведи на неё мышь и увидишь причину.

## Как работать

**Раскадровка.** Все кадры серии разложены по сценам. Цвет точки показывает статус: серый — нужно сделать, синий — на проверке, зелёный — утверждено.
Нажми на кадр, и справа откроется панель:

- **Нарисовать.** Студия собирает промпт (стиль + палитра + описание героев) и прикладывает референсы: фон локации и листы персонажей из кадра. Потом отправляет всё Кодексу. Картинка появится сама, обычно через 1–3 минуты.
- **Что поменять?** Напиши правку обычными словами и нажми «Перерисовать с правкой». Текущая версия уйдёт Кодексу как основа, остальное он сохранит.
- **Версии.** Все попытки сохраняются. Нажми на миниатюру, чтобы выбрать лучшую.
- **Утвердить.** Кадр готов к анимации.
- **Загрузить файл.** Если нарисовала где-то ещё, просто перетащи картинку на кадр.
- **⚠ Предупреждения.** Студия сверяет промпт с каноном: красное солнце, серебряная кровь, правый глаз в Приказе Лорда и так далее.
- **Заметка для Claude.** Сюда пиши вопросы по логике и лору. Я увижу их в следующем чате.

**Персонажи и Локации.** Это канонные референсы. Начинать лучше с них: лист героя и фон локации автоматически прикладываются к каждому кадру, поэтому внешность и место не «плывут». Кнопка «Нарисовать недостающие» сделает всё, чего не хватает.

**Иллюстрации.** Это библиотека картинок, которые можно брать референсами. Сюда попадает всё из папки `Аниме/`.
Иллюстрации книги с Google Диска добавляются так:
1. На Диске выдели нужные картинки и нажми «Скачать».
2. Перетащи скачанные файлы на большую рамку во вкладке «Иллюстрации». Можно много сразу.
3. Студия уменьшит их до 2048 px (оригиналы весят до 100 МБ, а GitHub такие не примет) и сохранит в `Аниме/Иллюстрации книги/`.
4. Открой персонажа или локацию, найди блок **«Референсы»** и нажми **«+ Из библиотеки»**. Рядом можно оставить пометку: «в детстве», «в бою».

Привязанные иллюстрации студия сама прикладывает Кодексу. Сначала по ним рисуется канонный лист персонажа. Пока листа нет, в кадры уходит сама иллюстрация.

**Стиль.** Лаборатория стиля: одни и те же кадры в 5 вариантах (ТВ-аниме, ретро-cel 90-х, гуашевые фоны, тушь и красный, кино-свет). Сравни их, выбери стиль для серии или добавь свой.

**Пакет для видео.** Собирает папку `studio/export/<серия>/`. В ней на каждый кадр лежат ключевая картинка, референсы `@Image1/@Image2` и `prompt.txt` с видео-промптом, а ещё общий «Монтажный лист». Дальше эти файлы можно загружать в Kling, Seedance или Pixverse.

**Очередь.** Здесь видно, что сейчас рисуется. Если задание упало с ошибкой, в нём есть лог.

## Режимы «Рисует:»

| Режим | Что нужно | Как работает |
|---|---|---|
| **Кодекс** | Codex CLI + вход в ChatGPT | Студия сама запускает `codex exec` с референсами. Платить отдельно не нужно: тратятся лимиты подписки. |
| **OpenAI API** | ключ в переменной `OPENAI_API_KEY` | Прямой вызов gpt-image. Платно, зато быстро. |
| **Вручную** | ничего | Студия готовит промпт и список референсов (кнопка «Скопировать промпт» во вкладке «Очередь»). Рисуешь в любом чате, результат перетаскиваешь на кадр. |

Настройки лежат в `studio/config.json`: команда Кодекса, таймаут, модель API.

## Как мы с Claude держим порядок

- Студия пишет каждую правку, утверждение и заметку в `studio/inbox.md`.
- После работы сделай **Commit → Push** в GitHub Desktop. Потом напиши мне: «проверь студию».
- Я прочитаю журнал и новые картинки, сверю их с книгой и каноном. Поправлю промпты, обновлю раскадровку и дам знать, что нужно перерисовать.
- Перед следующей работой в студии нажми **Fetch/Pull**, чтобы забрать мои правки.

## Где что лежит

```
Студия.bat                       ← запуск
studio/
  server.mjs                     ← сервер (Node.js, без зависимостей)
  public/                        ← интерфейс
  config.json                    ← кто рисует и как
  data/project.json              ← стили, палитры, персонажи, локации, правила канона
  data/episodes/s01e01.json      ← серия 1: сцены, кадры, промпты, версии, статусы
  data/stylelab.json             ← пробы стилей
  media/                         ← все сгенерированные картинки (по сериям и кадрам)
  inbox.md                       ← журнал правок для Claude
Аниме/Иллюстрации книги/         ← иллюстрации с Диска, уменьшенные студией
  canon/book/                    ← текст книги по главам
  tools/import_storyboard.py     ← перенос раскадровки .md в студию (Claude)
  export/                        ← пакеты для видео (не коммитятся)
Аниме/                           ← исходные материалы: листы, фоны, раскадровка
```
