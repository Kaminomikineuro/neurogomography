# Студия «Белая кровь»

Одно окно для всей работы над аниме: раскадровка по кадрам, референсы, промпты, генерация картинок через Кодекс, правки, версии и пакет для видео (Kling / Seedance / Pixverse).

```
Ты ──► Студия (браузер) ──► Кодекс рисует ──► картинка появляется в кадре
              │                                      │
              └── всё лежит в репозитории ◄──────────┘
                         │
                     Claude читает: канон, логика, промпты, журнал правок
```

## Запуск (Windows)

1. Один раз установи **Node.js** (https://nodejs.org, кнопка LTS).
2. Один раз дважды щёлкни **`Установить Кодекс.bat`**. Он поставит Codex CLI и откроет вход в ChatGPT.
   Устанавливаешь сама в «Терминале»? Тогда пиши `npm.cmd` и `codex.cmd`, а не `npm` и `codex`. Иначе PowerShell ответит «выполнение сценариев отключено».
3. Двойной клик по **`Студия.bat`** в корне репозитория. Откроется браузер с адресом http://localhost:4545.
   Чёрное окно не закрывай: это сервер студии.

Справа вверху должна гореть зелёная метка **«Кодекс на связи»**. Если она жёлтая, наведи на неё мышь и увидишь причину.

## Запуск на Mac

1. Установи Node.js (https://nodejs.org).
2. Для Кодекса один раз открой «Терминал» и выполни `npm i -g @openai/codex`, потом `codex login`.
3. Дважды щёлкни **`Студия (Mac).command`**. Если macOS не даёт его открыть: правый клик → «Открыть» → «Открыть».

## ⚠ Большие файлы не коммить напрямую

Оригиналы иллюстраций весят до 100 МБ. GitHub не принимает файлы больше 100 МБ, а большой Push обрывается с ошибкой «Remote disconnected».
Поэтому оригиналы **не клади в папку репозитория**. Перетащи их во вкладку **«Иллюстрации»**: студия сама уменьшит каждую до 2048 px (1–3 МБ).

**Большие картинки уже в папке?** Во вкладке «Отправка в GitHub» есть кнопка «Уменьшить все и сохранить оригиналы»: картинки больше 6 МБ станут 2048 px, а оригиналы уедут в папку «neurogomography — оригиналы» рядом с репозиторием.

**Если Push всё равно обрывается** — вкладка **«Отправка в GitHub»** → «Отправить порциями». Студия сама разложит изменения на порции по 80 МБ и отправит их по одной (Git берёт из GitHub Desktop). Неотправленный огромный коммит она тоже разложит обратно на порции, файлы больше 100 МБ спрячет от Git. Если студии не хватит входа в GitHub, она соберёт одну порцию и попросит нажать Push в GitHub Desktop, потом снова «Отправить порциями».

## Как работать

**Раскадровка.** Все кадры серии разложены по сценам. Цвет точки показывает статус: серый — нужно сделать, синий — на проверке, зелёный — утверждено.
Нажми на кадр, и справа откроется панель:

- **Нарисовать.** Студия собирает промпт (стиль + палитра + описание героев) и прикладывает референсы: фон локации и листы персонажей из кадра. Потом отправляет всё Кодексу. Картинка появится сама, обычно через 1–3 минуты.
- **Что поменять?** Напиши правку обычными словами и нажми «Перерисовать с правкой». Текущая версия уйдёт Кодексу как основа, остальное он сохранит.
- **Версии.** Все попытки сохраняются. Нажми на миниатюру, чтобы выбрать лучшую.
- **Утвердить.** Кадр готов к анимации.
- **Загрузить файл.** Если нарисовала где-то ещё, просто перетащи картинку на кадр.
- **⚠ Предупреждения.** Студия сверяет промпт с каноном: красное солнце, серебряная кровь, правый глаз в Приказе Лорда и так далее.
- **Заметка для Claude.** Сюда пиши вопросы по логике и лору. Я увижу их в следующем чате.

**Постановка сцены.** Над каждой сценой есть полоска: общий план, схема расстановки (вид сверху) и «Постановка» — кто где стоит, откуда свет, куда смотрит камера. Нажми на полоску, откроется панель сцены.
- Сначала нарисуй **общий план сцены**. Он уходит Кодексу в каждый кадр этой сцены вместе со схемой и предыдущим кадром, поэтому люди не «переезжают», а фон не повторяется.
- У кадра есть поле **«Непрерывность»**: поза и направление движения в этом кадре (например, «летит головой вниз»).
- Фон локации идёт только как образец места: Кодекс не копирует его ракурс. В крупных планах фон размыт.

**Перерисовать скопом.** Кнопка «☑ Перерисовать скопом» над раскадровкой. Нажимай на карточки или на «выбрать всю сцену» у заголовка сцены. Справа выбери, как перерисовать:
- **заново, с опорой на текущую** — новая постановка и фон, а старая картинка идёт черновиком (лица, позы). Подходит, когда поменялись место или расстановка;
- **поправить текущую** — меняется только то, что написано в правке;
- **с нуля**.
Общая правка добавится ко всем кадрам, а у каждого кадра можно написать свою. Своя правка из поля «Что поменять?» тоже попадает сюда: на карточке такого кадра значок ✎.

**Вставка из буфера.** Ctrl+V (на Mac Cmd+V) или кнопка «📋 Вставить» в панели кадра. Студия спросит: новая версия или референс.

**Персонажи и Локации.** Это канонные референсы. Начинать лучше с них: лист героя и фон локации автоматически прикладываются к каждому кадру, поэтому внешность и место не «плывут». Кнопка «Нарисовать недостающие» сделает всё, чего не хватает.

**Иллюстрации.** Это библиотека картинок, которые можно брать референсами. Сюда попадает всё из папки `Аниме/`.
Иллюстрации книги с Google Диска добавляются так:
1. На Диске выдели нужные картинки и нажми «Скачать».
2. Перетащи скачанные файлы на большую рамку во вкладке «Иллюстрации». Можно много сразу.
3. Студия уменьшит их до 2048 px (оригиналы весят до 100 МБ, а GitHub такие не примет) и сохранит в `Аниме/Иллюстрации книги/`.
4. Открой персонажа или локацию, найди блок **«Референсы»** и нажми **«+ Из библиотеки»**. Рядом можно оставить пометку: «в детстве», «в бою».

Привязанные иллюстрации студия сама прикладывает Кодексу. Сначала по ним рисуется канонный лист персонажа. Пока листа нет, в кадры уходит сама иллюстрация.

**Стиль.** Лаборатория стиля: одни и те же кадры в 5 вариантах (ТВ-аниме, ретро-cel 90-х, гуашевые фоны, тушь и красный, кино-свет). Сравни их, выбери стиль для серии или добавь свой.

**Видео.** В панели кадра есть блок «Видео» с подсказкой для инструмента из раскадровки (Pixverse, Kling или Seedance; Seedance есть внутри Pixverse). В подсказке:
- стартовый кадр и референсы `@Image1/@Image2` в нужном порядке, с кнопками «скачать»;
- промпт целиком, он уже содержит реплики для губ;
- negative.

Готовый ролик перетаскиваешь в этот блок. Версии хранятся, лучшую можно утвердить.

**Реплики.** Блок «Реплики» в панели кадра. У каждой реплики указано, кто говорит, и режим:
- **губы в кадре** — текст уходит в видео-промпт, чтобы губы двигались под слова (видео делаем без звука, голос накладываем потом);
- **голос за кадром** — губы не двигаются;
- **мысли / рассказчик** — тоже без губ.

Ещё у реплики есть отметка о сверке с книгой. Если реплика отличается от книги, рядом виден книжный вариант и кнопка «взять из книги». Полный отчёт лежит в `studio/canon/Реплики_Т2-01.md`.

**Монтаж.** Вся серия подряд. Где видео ещё нет, на нужное число секунд встаёт картинка кадра с лёгким наездом камеры. Реплики идут субтитрами. Ролики длиннее кадра обрезаются по хронометражу раскадровки. Клик по полосе внизу переносит к нужному кадру.
Кнопка **«Собрать видео серии»** склеивает всё в один файл (MP4 или WebM) в `studio/export/<серия>/`. Сборка идёт в реальном времени: 5 минут серии собираются около 5 минут. Вкладку в это время не сворачивай.

**Комикс.** Вкладка «Комикс» → «Собрать комикс автоматически». Студия раскладывает кадры серии по страницам:
- общие планы идут широкими панелями, крупные — парами, «взгляды» — узкими полосами, удары — наискосок и с линиями скорости;
- ключевые моменты получают целую страницу или страницу с **большой фигурой героя** во весь рост, а рядом обычную раскадровку. Фигуру Кодекс рисует на белом фоне (кнопка «Нарисовать фигуру»), студия вырезает её и обводит белым контуром;
- реплики из книги встают пузырями (речь, мысли, шёпот, крик…), пояснения — подписями, звуки — крупными буквами, есть «искра взглядов» и значок злости.
Всё двигается мышкой: пузыри, хвосты (красная точка), кадр внутри панели, колёсико — приблизить. Формат «Вебтун» — длинная лента для телефона. «Сохранить страницы PNG» кладёт страницы в `studio/export/<серия>/комикс/`. Подсказки для раскладки (какие кадры на всю страницу, подписи из книги, звуки) Claude ведёт в `studio/canon/comic/<серия>.json`.

**Вырезать кадр.** Кнопка в панели кадра. Пометка «можно вырезать» — только подсказка из раскадровки, решаешь ты.

**Пакет для видео.** Собирает папку `studio/export/<серия>/`. В ней на каждый кадр лежат ключевая картинка, референсы `@Image1/@Image2` и `prompt.txt` с видео-промптом, а ещё общий «Монтажный лист». Дальше эти файлы можно загружать в Kling, Seedance или Pixverse.

**Очередь.** Здесь видно, что сейчас рисуется. Если задание упало с ошибкой, в нём есть лог.

## Режимы «Рисует:»

| Режим | Что нужно | Как работает |
|---|---|---|
| **Кодекс** | Codex CLI + вход в ChatGPT | Студия сама запускает `codex exec` с референсами. Платить отдельно не нужно: тратятся лимиты подписки. |
| **OpenAI API** | ключ в переменной `OPENAI_API_KEY` | Прямой вызов gpt-image. Платно, зато быстро. |
| **Вручную** | ничего | Студия готовит промпт и список референсов (кнопка «Скопировать промпт» во вкладке «Очередь»). Рисуешь в любом чате, результат перетаскиваешь на кадр. |

Настройки лежат в `studio/config.json`: команда Кодекса, таймаут, модель API.

## Как мы с Claude держим порядок

- Студия пишет каждую правку, утверждение и заметку в `studio/inbox.md`.
- После работы сделай **Commit → Push** в GitHub Desktop. Потом напиши мне: «проверь студию».
- Я прочитаю журнал и новые картинки, сверю их с книгой и каноном. Поправлю промпты, обновлю раскадровку и дам знать, что нужно перерисовать.
- Перед следующей работой в студии нажми **Fetch/Pull**, чтобы забрать мои правки.

## Где что лежит

```
Студия.bat                       ← запуск
studio/
  server.mjs                     ← сервер (Node.js, без зависимостей)
  public/                        ← интерфейс
  config.json                    ← кто рисует и как
  data/project.json              ← стили, палитры, персонажи, локации, правила канона
  data/episodes/s01e01.json      ← серия 1: сцены, кадры, промпты, версии, статусы
  data/stylelab.json             ← пробы стилей
  media/                         ← все сгенерированные картинки (по сериям и кадрам)
  inbox.md                       ← журнал правок для Claude
Аниме/Иллюстрации книги/         ← иллюстрации с Диска, уменьшенные студией
  canon/book/                    ← текст книги по главам
  tools/import_storyboard.py     ← перенос раскадровки .md в студию (Claude)
  export/                        ← пакеты для видео (не коммитятся)
Аниме/                           ← исходные материалы: листы, фоны, раскадровка
```
