# Как сделать серии по новой главе

Порядок для Claude (из чата или из кнопки «🎬 Новая серия из главы» в студии). Делать целиком, от чтения главы до готовых кадров в студии. Образец того, как это должно выглядеть: серии 1–2 по Т2, гл. 1.

## 0. Что прочитать перед работой
1. `CLAUDE.md` — роли, данные, правила.
2. `studio/canon/book/README.md` — какие главы актуальные, а какие из старой печатной версии. **Если глава из старой версии — сначала предупреди автора** одной строкой и попроси актуальный docx. Не останавливайся, если автор уже сказал «делай».
3. Всю главу целиком: `studio/canon/book/<Т…>.txt`.
4. Образец раскадровки: `Аниме/1 серия - демка/Серия_1-2_раскадровка_Т2_гл1.md` — формат, длина кадров, язык промптов, блоки STYLE, палитры, токены героев.
5. `studio/data/project.json` — `characters` (токены `[ID]`), `locations`, `palettes`, `rules`, `questions`, `activeStyle`.
6. Визуальный канон: `Аниме/Карты и виды местности/Эльтарион/АРТ_Эльтарион_визуал_v1.md`.
7. Последние записи `studio/inbox.md` — правки автора, которые надо учесть (например: «Лиам прыгает ногами вперёд», «глаза Повелителя — обсидиановые»).

## 1. Разбить главу на серии и сцены
- Серия ≈ 4,5–5 минут экрана. Глава обычно = 2 серии. Финал серии — на сильной реплике или повороте.
- Сцена = одно место и одно непрерывное время. На каждую сцену — одна локация из `project.json → locations`.
- Если места нет в `locations` — добавь локацию: `id` (латиница, через дефис), `name`, `palette` (PAL-…), `prompt` (английский, только окружение, без людей). Если в одном месте есть разные состояния (курган / без кургана, небо / земля, до разлома / после) — это **разные локации**.
- Если появился новый герой — добавь в `characters`: `id` (латиница, заглавные), `name`, `group`, `token` (английский: возраст, телосложение, волосы, глаза, одежда — строго по книге), `sheetPrompt`. Внешность бери только из книги и `studio/canon/`; если в книге не сказано — добавь вопрос в `questions`.
- Номер новой серии: следующий свободный `sNNeMM` в `studio/data/episodes/`.

## 2. Написать раскадровку
Файл: `Аниме/<Т2 гл.2> - раскадровка/Серия_<N>-<M>_раскадровка_<Т2_гл2>.md`. В самом начале файла — шапка для импорта:

```
<!-- studio
ep: s01e03 | Серия 3 — «Название» | сцены 1-7 | финал: на чём кончается
ep: s01e04 | Серия 4 — «Название» | сцены 8-13
chapter: studio/canon/book/Т2-02 Название.txt
source: Т2, гл. 2 «Название»
-->
```

Сцена: `## СЦЕНА 1. Название · ~40 с · @council` (после `@` — id локации).
Кадр (как в образце):

```
**1.4** · 4 с · Крупный, статика · Pixverse
Кадр: что видно, по-русски, коротко.
Звук: Лиам: «точная реплика из книги». / VO Лиама: «мысли». / шумы.
IMG: `[LIAM] ..., PAL-COUNCIL, STYLE`
VID: `slow push-in, wind moves his hair`
```

Правила:
- **Реплики — дословно из книги** (в «Звук»), с именем говорящего. Мысли — `VO Лиама: «…»`, рассказчик — `VO (из нарратива): «…»`. Голос из-за кадра — `Рой (за кадром): «…»`.
- **Хронометраж под липсинк:** русская речь ≈ 13 знаков в секунду. Если реплика длиннее кадра — говорящий остаётся в кадре с губами, а хвост реплики идёт голосом за кадром на вставке (глаза, реакция собеседника, деталь). Такие кадры получают id с буквой: `8.8a`, `8.8b`.
- **Акценты на взглядах, как в аниме:** сверхкрупные вставки глаз в ключевые моменты (решение, угроза, узнавание). Глаза героев — строго по канону (Повелитель — обсидиановые).
- Темп: диалоги 3–6 с, экшен 1–3 с. Один кадр = одно действие и одно движение камеры.
- **IMG** — по-английски, токены героев `[ID]`, палитра `PAL-…` и `STYLE` в конце. Не описывай фон локации подробно — его даёт референс локации. `IMG: = кадр 1.2`, если картинка та же.
- **VID** — только движение и камера.
- Инструмент: Pixverse — простые движения; Kling — одно сложное действие; Seedance — несколько героев, бой, связки.
- Правило 180°: в диалоге и бою один герой всегда слева, другой справа.
- Сомнительные кадры помечай `[можно вырезать]`.
- В конце файла — раздел «⚠ На усмотрение автора»: что придумано сверх книги.

## 3. Загрузить в студию
```
python studio/tools/import_storyboard.py "Аниме/<папка>/<файл>.md"
python studio/tools/lines.py s01e03 s01e04
```
(На Windows вместо `python` может быть `py`.) Импорт не затирает уже нарисованное и правки студии. `lines.py` разбирает реплики и пишет отчёт сверки с книгой `studio/canon/Реплики_<серии>.md` — проверь строки «≈ отличается» и «— нет в тексте».

## 4. Постановка сцен (в `studio/data/episodes/<серия>.json`, поля сцены)
- `staging` — по-русски: где стоят герои и предметы, откуда свет, кто слева/справа, куда смотрит главная камера, что меняется по ходу сцены (например: «до кадра 6.9 разлома нет»).
- `masterPrompt` — по-английски: общий план сцены, все на своих местах, с токенами `[ID]` и `STYLE` в конце.
- У кадров экшена — поле `continuity` (по-английски): поза и направление движения, чтобы соседние кадры совпадали.
- Если есть Python с PIL — можно нарисовать план сверху, как `studio/canon/plans/*.png`, и записать путь в `plan`. Если нет — пропусти.

## 5. Подсказки для комикса
Сделай `studio/canon/comic/<серия>.json` по `studio/canon/howto/comic.md`.

## 6. Канон и вопросы
- Новые жёсткие правила (цвет крови, глаз, оружие…) — в `project.json → rules` (регулярки `when` / `unless`).
- Всё, что не ясно из книги, — в `project.json → questions`.

## 7. Ответ автору
Коротко, по-русски: сколько серий, сцен и кадров; какие новые герои и локации надо нарисовать первыми (вкладки «Персонажи» и «Локации»); вопросы. Напомни: сначала листы героев и фоны локаций, потом общие планы сцен, потом кадры.
