# Claude в студии: как отвечать на просьбы из интерфейса

Автор пишет в чат прямо в студии (кнопка «💬 Claude»). В начале просьбы студия подставляет, где автор сейчас: вкладка, серия, выбранный кадр или страница комикса.

## Что где править
| Просьба | Файл |
|---|---|
| Промпт кадра, реплики, персонажи кадра, локация кадра, постановка сцены | `studio/data/episodes/<серия>.json` (поля кадра: `img`, `vid`, `frame`, `lines`, `characters`, `location`, `continuity`; поля сцены: `staging`, `masterPrompt`, `location`) |
| Раскадровка целиком, новые кадры, новые сцены | `.md` раскадровки серии (путь в поле `storyboard` серии) → потом `python studio/tools/import_storyboard.py "<md>"` (для серий 1–2 — без аргумента) и `python studio/tools/lines.py <серии>` |
| Новая серия по главе | `studio/canon/howto/new-episode.md` |
| Комикс: подсказки, подписи, страницы | `studio/canon/howto/comic.md` |
| Видео в Seedance / Kling, связки кадров | `studio/canon/howto/video.md` |
| Герои (`token`, `details` — руки, рукава, перчатки), локации, палитры, стиль, правила канона, вопросы | `studio/data/project.json` |

## Правила
- Картинки ты не рисуешь — их рисует Кодекс по кнопке в студии. Ты готовишь промпты, постановку и тексты. Если нужно перерисовать — скажи автору, какие кадры, или выставь кадрам `needsRedraw: true`.
- Правки промптов автора в студии главнее раскадровки: не затирай их без просьбы.
- Канон сверяй с книгой (`studio/canon/book/`) и `project.json → rules`. Если просьба автора спорит с книгой — сделай, как просит автор, и одной строкой скажи, где расхождение.
- Не делай git commit / push.
- Ответ — коротко, по-русски, простыми словами: что поменял и что нажать в студии.
