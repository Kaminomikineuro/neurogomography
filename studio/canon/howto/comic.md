# Комикс: подсказки для автосклейки и правки страниц

## Подсказки серии — `studio/canon/comic/<серия>.json`
Студия раскладывает кадры по страницам сама, а этот файл говорит ей, где главное. Образец: `studio/canon/comic/s01e01.json`.

| Поле | Что это |
|---|---|
| `splash` | id кадров на целую страницу (1–2 на сцену максимум: открытие места, поворот, кульминация). |
| `hero` | id кадров для страницы с большой фигурой героя во весь рост (герой встаёт, принимает решение, приземляется, бросает вызов). 2–4 на серию. |
| `eyes` | id кадров-«взглядов» — узкие полосы на всю ширину. |
| `spark` | id кадров, где двое смотрят друг на друга в упор — «искра взглядов». |
| `stickers` | `{ "id": "anger" }` — значок злости. |
| `captions` | `{ "id": "текст" }` — подписи-пояснения. **Только короткие цитаты из книги** (1–2 предложения), без пересказа своими словами. Брать то, что не видно на картинке: мысли рассказчика, время, место, вес момента. 1 подпись на 2–4 панели, не чаще. |
| `sfx` | `{ "id": "ЗВУК" }` — звукоподражания по-русски, коротко, по полю «Звук» кадра (удар, хруст, взрыв, стук). Тихие звуки — строчными («тук… тук…»), громкие — заглавными с «!». |
| `kind` | `{ "id": "yell" }` — вид пузыря, если по реплике он не очевиден: `speak`, `think`, `whisper`, `yell`, `scream`, `burst`, `spooky`, `digital`, `dreamy`. |
| `sides` | `{ "номер сцены": { "LIAM": "r", "LORD": "l" } }` — с какой стороны кадра стоит говорящий (по постановке сцены), туда смотрит хвост пузыря. |
| `darkScenes` | номера сцен, где фон ленты вебтуна тёмный (разлом, ночь, страх). |
| `color` | `"full"`, `"ink-red"` (ч/б + красный) или `"ink"` (ч/б) — цвет комикса по умолчанию. |

После правки подсказок автор жмёт «↻ Собрать заново» во вкладке «Комикс» (или студия сама предложит).

## Готовые страницы — `studio/data/comics/<серия>.json`
Если автор просит поправить конкретную страницу («на странице 5 убери подпись», «сделай страницу 12 ч/б»), правь этот файл напрямую:
- `pages[i]` — страница (`i` с нуля: страница 5 = `pages[4]`); `w`, `h`, `bg` (цвет фона), `color` (цвет страницы);
- `panels[]` — `shot` (id кадра), `poly` (углы панели в пикселях страницы), `crop` (`s` — приближение, `x`/`y` 0…1 — сдвиг), `fx` (`speed`, `speedv`, `focus`, `flash`, `dark`), `border`, `color`, `art` (своя картинка панели);
- `bubbles[]` — `kind`, `text`, `x`, `y`, `tail` ([x, y] или null), `size`, `rot`;
- `marks[]` — `spark` (две точки `pts`) или `anger`;
- `figure` — большая фигура героя: `art`, `x`, `y`, `h`.
Страница манги 1000×1414, поля 44, промежуток между панелями 16. Не трогай `arts[*].versions` — это нарисованные картинки.
