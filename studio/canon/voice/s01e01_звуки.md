# Серия 1 — звуки и музыка для склейки

Сейчас эти звуки синтезирует сама склейка (`studio/tools/cut.py`). Если положить свой файл с **точно таким именем**
в папку `studio/media/s01e01/sfx/` (mp3 или wav), склейка возьмёт его вместо синтеза. Длину подгонять не надо:
короткий файл повторится, длинный обрежется. Громкость Claude подстроит в листе `studio/data/montage/s01e01.cut.json`.

Родной звук Kling уже стоит на пустыне (ветер, море), полёте птицы (крылья), двери (кольцо, створка) и шагах.
Голоса — ваши файлы из `Аниме/1 серия - демка/01_Утвержденные_реплики/`, без эффектов.

## Музыка — важнее всего

| Имя файла | Что | Длина | Где в склейке |
|---|---|---|---|
| `music_open` | тема открытия: тёмное восточное фэнтези, низкие струнные, барабаны издалека, без вокала; нарастает к замку | 20 с | 0:00–0:18, пустыня → замок → птица |
| `music_council` | фон совета: тихий низкий гул или виолончель, без мелодии, чтобы не мешать речи; напряжение | 30 с | 0:18–0:46 |
| `music_decision` | нарастание: Лиам замолкает, барабанит, встаёт; в конце — тяжёлый удар | 8 с | 0:46–0:54 |
| `music_end` | короткая решительная тема ухода Лиама, затухает на последнем кадре | 8 с | 1:01–1:09 |

## Шумы

| Имя файла | Что | Длина | Где |
|---|---|---|---|
| `room` | тишина каменного зала (room tone): воздух, далёкий ветер за стенами | 30–60 с | весь совет |
| `sand_glass` | стрекотание (сейчас синтез, вам он нравится — можно не трогать) | — | весь совет |
| `window` | распахиваются деревянные створки окна, звякают петли | 1 с | 0:14, птица у окна |
| `wind_strong` | порыв горячего ветра в открытое окно | 3 с | 0:14–0:22 |
| `leather` | скрип кожаных латных рукавиц, кулаки давят на камень | 1 с | 0:38, кулаки Бельфи |
| `taps` | пальцы барабанят по каменному подлокотнику и замирают | 3 с | 0:46 |
| `heart` | медленное глухое сердцебиение | 3–4 с | 0:46–0:49 |
| `scrape` | тяжёлое каменное кресло отодвигается | 1 с | 0:51, Лиам встаёт |
| `boom` | низкий глухой удар-акцент (как в аниме на решении героя) | 2–3 с | 0:51 |

Как отдать: положить файлы в `studio/media/s01e01/sfx/` → GitHub Desktop → Commit → Push. Дальше Claude пересоберёт склейку.
