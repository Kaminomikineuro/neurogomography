# ❄ Наш зимний маршрут — офлайн-приложение

Ками и Аня · 18.12.2026 — 06.01.2027 · Германия, Чехия, Австрия, Словакия.

PWA: один раз открыть по ссылке, добавить на экран «Домой» — дальше всё работает **без интернета**:
лента поездки, карта маршрута, билеты и брони (PDF/скриншоты), города, напоминания.

Адрес после публикации: **https://kaminomikineuro.github.io/neurogomography/**

## Что где лежит

```
winter-trip/
├── app/                      ← это и есть сайт (публикуется только эта папка)
│   ├── index.html
│   ├── data/trip.json        ← ПЛАН ПОЕЗДКИ (без личных данных!)
│   ├── js/                   ← код (без сборки, обычные ES-модули)
│   ├── css/, fonts/          ← стиль и шрифты Cormorant Garamond + Rubik (локально)
│   ├── vendor/pdfjs/         ← просмотрщик PDF (локально, без CDN)
│   ├── vendor/fflate/        ← упаковка .zip для обмена
│   ├── icons/                ← иконка приложения
│   ├── manifest.webmanifest
│   └── sw.js                 ← офлайн-кэш (генерируется автоматически)
└── tools/                    ← инструменты (проверка trip.json, карта, иконки, sw.js)
```

Личные файлы (билеты, брони, паспорта) **не попадают ни в код, ни в интернет**:
они добавляются кнопкой «Добавить файл» на телефоне и живут только в памяти телефона (IndexedDB).

## Публикация на GitHub Pages (один раз)

Репозиторий `Kaminomikineuro/neurogomography` уже есть, приложение лежит в ветке
`claude/beautiful-sagan-xkldz1`.

1. **Слить ветку в `main`.** На GitHub: вкладка *Pull requests* → *New pull request* →
   base: `main`, compare: `claude/beautiful-sagan-xkldz1` → *Create* → *Merge*.
   (Или попросите меня открыть pull request.)
2. **Включить Pages.** *Settings* → *Pages* → *Build and deployment* → *Source*: **GitHub Actions**.
3. **Запустить публикацию.** *Actions* → «Зимний маршрут → GitHub Pages» → *Run workflow*
   (дальше она запускается сама при каждом изменении в `winter-trip/` на `main`).
4. Через 1–2 минуты сайт откроется по адресу https://kaminomikineuro.github.io/neurogomography/

> Публикуется только папка `winter-trip/app`. Остальные файлы репозитория на сайт не попадают.
> Но сам репозиторий **публичный** — `trip.json` может прочитать кто угодно, поэтому в нём нет
> номеров броней, PNR, паспортов и названий секретных отелей.

## Установка на телефон

**iPhone (Safari):** открыть ссылку → кнопка «Поделиться» ⬆︎ → «На экран Домой» → «Добавить».
Открывать приложение **с иконки**, а не из Safari: у установленного приложения своё хранилище.

**Android (Chrome):** открыть ссылку → меню ⋮ → «Установить приложение» (или «Добавить на гл. экран»).

После установки:

1. Открыть приложение один раз с интернетом, подождать 10 секунд (скачивается офлайн-кэш ~3 МБ).
2. ⚙️ → «Проверить офлайн-готовность» — должно быть ✅ по всем пунктам.
3. ⚙️ → «Запросить постоянное хранилище».
4. Добавить файлы: вкладка «Документы» → «＋ Добавить файл», привязать к поезду/рейсу/городу.

## Проверка в авиарежиме — чек-лист

Пройти на **обоих** телефонах до вылета (лучше за неделю).

**Офлайн и перезапуск**
- [ ] Включить авиарежим (и выключить Wi-Fi). Закрыть приложение смахиванием. Открыть с иконки — открывается, видна лента.
- [ ] Перезагрузить телефон. В авиарежиме открыть приложение — всё на месте: план, отметки, файлы.
- [ ] Переключить все 4 вкладки: Лента, Карта, Документы, Города — ничего не грузится «бесконечно».

**Документы без сети**
- [ ] Открыть PDF-билет — страницы видны, кнопки −/+ работают.
- [ ] «▣ Показать QR» — белый экран, крупно; «+» увеличивает QR; экран не гаснет.
- [ ] Открыть скриншот (картинку).
- [ ] «↗ Поделиться» — открывается системное меню (можно отменить).

**Лента и время**
- [ ] ⚙️ → «Тестовое сейчас» = `23.12.2026 15:30` → в ленте подсвечены «Сегодня» (23 декабря) и «Следующее» (вещи с ресепшена), баннер «Скоро» показывает поезд в Прагу и тур.
- [ ] Отметить пункт галочкой → зачёркнут; закрыть/открыть приложение → отметка сохранилась.
- [ ] Вернуть настоящее время.

**Карта и навигатор**
- [ ] Карта двигается пальцем, щипок увеличивает. Тап по городу — карточка; тап по линии/значку поезда — отрезок с временем.
- [ ] «Открыть в навигаторе» открывает выбранное приложение (в авиарежиме карта там будет только если скачана офлайн-область).

**Обмен между телефонами**
- [ ] Ками: ⚙️ → «🎁 Для Ани (без секретов)» → отправить .zip в Telegram (себе в «Избранное» или Ане).
- [ ] Аня: сохранить файл из Telegram → ⚙️ → «⬇︎ Импорт .zip» → видны план, отметки, файлы.
- [ ] У Ани в Фантазиаленде вместо отеля — «Живём в отеле Фантазиаленда 🎁», секретных файлов нет.

**Секрет**
- [ ] Ками: ⚙️ → «Задать PIN» → карточка Фантазиаленда показывает заглушку → «🔑 Ввести PIN» → виден отель.
- [ ] «🔒 Скрыть» → снова заглушка.
- [ ] Тестовое сейчас = `04.01.2027 09:00` на телефоне с полным экспортом → секрет раскрылся сам.

**Напоминания**
- [ ] 🔔 → «Экспорт в календарь (.ics)» → события появились в календаре (см. ниже).
- [ ] В авиарежиме дождаться любого напоминания (можно добавить тестовое на +5 минут и экспортировать).

## Честно о том, что ненадёжно, и что делать

| Что | Риск | Запасной вариант |
|---|---|---|
| **Уведомления из PWA** | На iPhone офлайн-уведомления по расписанию из веб-приложения не работают. | Напоминания экспортируются в **календарь** (.ics) — он напомнит без сети и с закрытым приложением. В самом приложении — баннер «Скоро». |
| **.ics на Android** | Google Календарь на телефоне не открывает .ics и игнорирует будильники из файла. | Импорт через calendar.google.com → Настройки → Импорт (на компьютере, до поездки), уведомление по умолчанию «в момент события». События стоят ровно во время напоминания, поэтому сработают. Samsung Calendar открывает .ics сам. |
| **.ics на iPhone** | Из установленного приложения меню «Поделиться» может не предложить «Календарь». | «Сохранить в Файлы» → открыть файл в «Файлах» → «Добавить все». |
| **Хранилище iPhone** | iOS может удалить данные веб-приложения при острой нехватке памяти. | Держите свежий .zip-экспорт в Telegram/«Файлах»; PDF билетов — копией в «Файлах»; посадочные — в Wallet. |
| **Секреты** | Это «шторка», а не шифрование: на телефоне с полным экспортом данные внутри есть. | Для Ани — экспорт «без секретов»: на её телефоне их просто нет. |
| **QR в PDF** | Некоторые сканеры плохо читают QR с экрана при низкой яркости. | Яркость на максимум; «+» увеличить QR; надёжнее всего — отдельный скриншот QR как картинка. |
| **Навигаторы** | `om://` и `maps://` открываются только при установленном приложении; без скачанных офлайн-карт навигатор без сети не построит путь. | Заранее скачать офлайн-области: Google Maps (Росток, Берлин, Дрезден, Прага, Вена, Братислава, Кёльн) или регионы в Organic Maps. |
| **Обновления** | Новая версия приходит, только когда телефон онлайн и приложение открыто. | После каждого изменения открыть приложение с интернетом; появится полоска «Есть новая версия». |

## План: `app/data/trip.json`

Все времена — местное время поездки (CET, `+01:00`, одинаково во всех четырёх странах зимой).
`[уточнить]` в любом тексте подсвечивается в приложении жёлтым.

```jsonc
{
  "revision": 1,                 // увеличивайте при каждом изменении — телефоны подхватят новый план
  "tz": "+01:00",
  "cities": [{
    "id": "prague", "name": "Прага", "local": "Praha", "flag": "🇨🇿",
    "lat": 50.087, "lng": 14.421,
    "kind": "stay",              // stay — ночуем; daytrip — на день; transit — проездом
    "from": "2026-12-23", "to": "2026-12-26", "nights": 3,
    "hotel": { "name": "…", "addressLocal": "адрес для таксиста", "address": "", "phone": "",
               "checkIn": "с 15:00", "checkOut": "до 11:00", "lat": null, "lng": null },
    "station": { "name": "Praha hlavní nádraží", "lat": 50.0833, "lng": 14.4353 },
    "places": [{ "name": "Староместская площадь", "local": "Staroměstské náměstí", "lat": …, "lng": …, "icon": "🎄", "note": "" }],
    "notes": "…",
    "secret": { "revealAt": "2027-01-04T00:00", "placeholder": "Сюрприз 🎁" }   // необязательно
  }],
  "segments": [{
    "id": "dre-pra", "mode": "train",        // train | nighttrain | flight | bus | taxi
    "from": "dresden", "to": "prague", "fromName": "Dresden Hbf", "toName": "Praha hl.n.",
    "dep": "2026-12-23T17:00", "arr": "2026-12-23T19:20", "approx": true,
    "number": "EC 179", "carrier": "", "coach": "254", "seat": "61", "platform": "",
    "status": "booked",                      // booked | todo | decide | option
    "options": [{ "label": "…", "dep": "…", "arr": "…", "price": "…" }],  // если ещё выбираем
    "daytrip": false, "hideOnMap": false, "notes": ""
  }],
  "days": [{
    "date": "2026-12-23", "city": "prague", "title": "Дрезден → Прага",

      "id": "i2304", "time": "17:00", "approx": true,

      "place": { "name": "…", "lat": …, "lng": … },          // точка для навигатора
```

Документы в `trip.json` **не хранятся**: файл привязывается к пункту, отрезку или городу на телефоне.

### Как обновлять план

- **Мелочи** (время, адрес, номер вагона, свой пункт) — прямо в приложении кнопкой «✎ Изменить».
  Правки хранятся поверх плана и **не стираются**, когда выходит новая версия `trip.json`.
- **Крупно** (настоящие брони): ⚙️ → «⬆︎ Экспорт trip.json» → **«Без секретов»** → пришлите файл мне
  (или просто перешлите письма-подтверждения текстом). Я обновлю `trip.json`, увеличу `revision`, опубликую —
  телефоны получат новый план при следующем открытии с интернетом.
- Проверка файла перед публикацией: `node winter-trip/tools/check-trip.mjs` (запускается и автоматически).

### PDF-ки через Claude: «пакет документов»

Можно не раскладывать файлы руками, а прислать все PDF и скриншоты Claude. Он:

1. прочитает билеты и брони и впишет в `trip.json` **публичные** данные: время, номер поезда или рейса, город, отель (кроме секретного);
2. разложит файлы по папкам и привяжет каждый к своему поезду, рейсу, городу или пункту;
3. соберёт личные данные (вагон и место, номера броней, адреса, секретный отель) вместе с файлами в **пакет** `.zip`
   (`tools/make-pack.mjs`). Пакет отдаётся файлом в чат и **не попадает в репозиторий** (`*.zip` и `private/` в `.gitignore`).

На телефоне: ⚙️ → «⬇︎ Импорт .zip» → «Добавить». Пакет **ничего не заменяет**: ваши правки и отметки остаются,
а повторный импорт того же файла не создаёт дублей. Потом для Ани — как обычно, «🎁 Для Ани (без секретов)».

## Для разработчика

- Никакой сборки: открыть `app/` любым статическим сервером, например `python3 -m http.server -d winter-trip/app`.
- Тестовое время: `?now=2026-12-23T15:30` в адресе или ⚙️ → «Тестовое сейчас».
- `tools/gen-sw.mjs` — пересобрать список офлайн-кэша (делает GitHub Actions при публикации).
- `tools/build-map.mjs` — перегенерировать контуры карты (Natural Earth, `npm install` в `tools/`).
- `tools/render-icons.mjs` — PNG-иконки из `icons/icon.svg` (нужен Playwright).
- Лицензии: pdf.js — Apache-2.0, fflate — MIT, шрифты — SIL OFL, контуры стран — Natural Earth (public domain).
