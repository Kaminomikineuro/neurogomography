# Le Petit Chat — Домик котика

Небольшая 3D-демка в духе «Маленького принца»: рыжий котик в жёлтом шарфике гуляет по крошечной планете,
собирает клубок, рыбку и упавшую звезду и возвращается спать в свой круглый домик с ушками на крыше.

Всё в одном файле `index.html`: Three.js (r160, с jsDelivr), процедурные модели, toon-шейдинг,
бумажное зерно поверх кадра, процедурная музыкальная шкатулка и «мяу» на WebAudio. Внешних ассетов нет.

## Запуск

Открыть `index.html` в браузере (нужен интернет для Three.js и шрифтов) или поднять сервер:

```sh
cd cat-planet && python3 -m http.server 8000
# http://localhost:8000
```

## Управление

| Клавиша | Действие |
|---|---|
| WASD / стрелки | идти |
| E / пробел | говорить, поднимать, читать дальше |
| M | мяукнуть |
| мышь (тянуть), Q / R | повернуть камеру |
| колесо | приблизить / отдалить |

На телефоне — джойстик слева, кнопки «лапкой» и «мяу» справа.

## Что на планете

- домик котика (табличка, мисочка, дымоход с дымом)
- гордая Ромашка, которая подсказывает, где что искать
- фонарь, который можно зажечь
- пруд с корзинкой, большое дерево, два вулкана (один потухший), кратеры
- упавшая звезда на тёмной стороне планеты
